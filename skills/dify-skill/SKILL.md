# dify-skill Dify 知识库问答

## 业务流程

```
用户提问 → askDify → Dify Chat API → 返回 AI 回答 → 展示回答卡片
```

## 原子接口

| 接口 | 作用 | 组件 | 前置条件 |
|------|------|------|----------|
| askDify | 向 Dify 知识库提问 | answer-card | 用户提出了知识库相关问题 |

## 用户意图分流

### 直接意图（触发本 SKILL）
- "请问..."、"怎么..."、"什么是..."
- 产品咨询、政策问题、知识问答
- 客服类问题

### 意图分流规则
- 用户提问知识库相关问题 → `askDify`
- 用户闲聊/打招呼 → 不调用本接口，由 Agent 直接回复
- 用户问题不明确 → 反问澄清
