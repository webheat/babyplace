广州高铁直达，一座被严重低估的低调古城，游玩回来后劲太大了！周末古城citywalk
==========================================

广州老西关citywalk去腻了，

  

潮汕古城citywalk试过没？

  

一提到潮汕，人们第一个想到的总是潮州和汕头，但阿珍这次却来到了比较低调的揭阳古城。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyiaHdv5WiahEnoLjxhicMWaVZnKMtX6dBNr3GSMXIKHyeInx2MnY9aXzUQ/640?wx_fmt=jpeg)

  

相比起潮州和汕头，揭阳会没有那么商业化，但该有的古城人文气息和当地美食一样都不会少。

  

个人觉得单纯体验古城citywalk，揭阳古城会比潮州牌坊街、汕头小公园更舒服。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyEQia4JJSOVZ6W4ST8xfckaYnCGP2ht1NVWTYf8Q1rfRia9icEenEHcTyQ/640?wx_fmt=jpeg)

  

从广州南、广州东、新塘都有高铁动车去揭阳，用时2～3小时就可以到达揭阳。

  

选择揭阳站会离古城更近，出站换乘106路公交可以去到进贤门总站，下车就是古城景区。也可以打车，只需27分钟左右就到进贤门。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjy6wQJwicJB75F20dg7afU4tkibKI6dRWUpD4vibeIN5IEMarJrk5YBpjKA/640?wx_fmt=jpeg)

  

选择潮汕站离古城较远，出站可以乘坐专线大巴到达进贤门总站，用时1小时左右。

  

揭阳还有一个国际机场，同样有专线大巴可以直达进贤门总站。

  

揭阳古城的景点基本都靠在一起，美食也都大多分布在街头巷尾，边玩边吃超赞的。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjy4qhI5Z9p4dr9NH3nXycgbAX3J2TPTFOJ2Z8KicIibBfXMaIFdq4Nds1A/640?wx_fmt=jpeg)

  

进贤门 ➡️ 揭阳学宫 ➡️ 禁城 ➡️ 石狮桥 ➡️ 丁日昌故居 ➡️ 打铜街 ➡️ 青狮文化区 ➡️ 中山路 ➡️ 雷神庙 ➡️ 城隍庙 ➡️ 学宫广场 ➡️ 百兰山馆 ➡️ 双峰寺 ➡️ 往回走到进贤门

  

按照上面这个路线，基本就把揭阳古城逛了一遍，算上拍照打卡、吃饭休息的时间，一天时间刚刚好。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyGCy9W2Vbz8ibAiaZnKlXC9ntFSAAYQZnwLC104YMFjJM1Iw0YpLNic5icw/640?wx_fmt=jpeg)

  

进贤门是揭阳古八景之一，也是揭阳的地标，相当于广州小蛮腰的地位。

下车就可以看到进贤门城楼，矗立马路中央气势浑宏，据说走过进贤门有学子高中，遇人贤良的好意头。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjy23GDSW2ym544W9ibdBVictAooFbajSzXCYCBaPGTknC5ia5OPhVibXsQlQ/640?wx_fmt=jpeg)

  

揭阳学宫也是必看的景点，免费开放，周一闭馆。穿过老城的市井气，如今所见的揭阳学宫由21座单体建筑构成，共计130多间房屋构成。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyczIykoyPfOiaVeaJ0Es7FCibk560Rke1Yz5dMiaj4f0c7nm2zB72VYHCA/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyMrfEN8FlFuSZZ1xokONMXBvmhnOvQeqzUXGHdBDuV4RITCO2WNbZ4g/640?wx_fmt=jpeg)

  

规模比我想象的要大得多，颇有点小故宫的感觉，红墙绿瓦十分好看，在这里拍照超级出片，特别是左侧的红墙长廊，有种穿越时空的即视感。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjysmh2nlgaicbJdCudxWXvC317soJgicl0uNQmWcWH8Jc09Umd93LAnTZQ/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyUibeNyPjXnFXY0J3s6u5JyEodvkvQH8LhUPlJoSv3lOgibahkeVasBIw/640?wx_fmt=jpeg)

  

逛完学宫就开始古城citywalk，从学宫旁边的小巷走进去就可以看到揭阳的禁城，是古揭阳县的内城墙，始建于元朝1353年。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyicPAicgv62OjBuruMvicWqIIM3brDPKyQ5BacUibnUuKRiadv28wXPZiaMgQ/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyWclhqa2Q8LsdrTYjEJv4suTlVo13ZTJ9JKVPmCgOpSvFlzbSMjR1PA/640?wx_fmt=jpeg)

  

从斑驳的古城墙可以感受到它历经的沧桑，而创意涂鸦墙又体现了古城的生机盎然。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyhm5Lib0eQnL8Ks35FvtEuDTWbbLycDYl9ico0E36z0viayIB9RzZouPGA/640?wx_fmt=jpeg)

  

往前走就是揭阳最出名的石狮桥，桥头伫立着一座喜庆的红石狮子，每年正月十一当地有“行头桥”习俗，想来摸狮子的人群围得水泄不通。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyKuzibibDyFqSgJia5Gv7tmRWPSP7L2j3G91TYVZ6q8S5raayiavQBShDIA/640?wx_fmt=jpeg)

  

之前石狮子被摸得秃噜皮了，正月十一就锁起来了，平时没人就可以过来摸摸，据说摸石狮子会带来好运，想生男孩要摸狮子耳朵哦。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyjEMqjHm5mUxtt970UPDpR7rnDlWK4e7IXctHdTsic6ZJnNvKEzwdJsg/640?wx_fmt=jpeg)

  

过了石狮桥就是打铜街，这里也曾是县城商埠中心，店铺林立，理发店、日杂小食档、打铜打锡金属加工厂…

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyHYeZcTaiaIFgjeibxed5FGZBKa1H1fS8GPdmwrTiawgxbre8NZvEIxJIQ/640?wx_fmt=jpeg)

  

这些街头铺面已经见证这座城近两个世纪的历史，走在街上可以感受到揭阳浓厚的历史文化底蕴，这里依旧是当地人居住生活的地方，市井烟火气十足。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyp45ZLxHXd4yDbHKc8oB1YrGB5hNo5bxRjO3aJappQysE2jK44hVuNQ/640?wx_fmt=jpeg)

  

其实打铜街两旁的小巷四通八达，穿梭在小巷中，都是些没有经过雕琢的老建筑，感受古城生态的原滋原味。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjy9kVfgqw1bwjCfE8VarTbVNrsRcEsShoqBsR86CMcT4TOE3ty0zfAJg/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyEUSzl9NLz2njKuhibjRrTJtqX1iad0SW4OyibO71BeqbLaiaMmtSHjWSmw/640?wx_fmt=jpeg)

  

来到中山路映入眼帘的是一排排老旧骑楼，有一种古朴悠闲的感觉，现在是淡季早上10点多了，很多商铺还没有开门，街上的人流也不多。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjy7MoO2JSOD87KLXsPaSW89T2DgegJ7g11X4YzfGz8VytnjBQPGwA2qQ/640?wx_fmt=jpeg)

  

这种清闲的感觉才是最棒的，如果是旺季人挤人，古城既使再美，在拥挤的人群中，好心情也会损失一大半。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyK2QlQzJfvOYeXjU0lRsEl26FQSxDIiaibDZybALeia4cfv1SZjb75atAA/640?wx_fmt=jpeg)

  

我非常享受这种慢慢悠悠走在古城街头巷尾的感觉，把遇到的人或事就记录下来。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjyB0tjv7hngFOC6UVM16kSYtiaoota7JsveK5oM1X9gHic2JtSoJYxCtSw/640?wx_fmt=jpeg)

  

两位老师带着一队小盆友来中山路游玩，老师说着中山路的趣事，小盆友们脸上笑开了花，这一幕真的太有爱了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjypuSTEEzItwFYSXuzWuGViaJrcmDUic66pELibSEU6r1FnHrWWCQ20kWtg/640?wx_fmt=jpeg)

  

关于揭阳古城还有很多好玩有趣的景点没写，城隍庙、双峰塔、榕城西湖这些都值得一去。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjySBewOKhbgOMLzI9wZaxtZe5ic9UuRrqoKw5eblICPdicg8hBPG5DW4tg/640?wx_fmt=jpeg)

  

其实不同的时间点过来揭阳游玩，感受都是不一样的。

  

过年旺季整个古城都在舞龙舞狮，“英歌舞”巡游，无数烟花爆竹在空中绽放。

  

“凑劳热”的喜庆气氛烘托到了顶点，参加过一次肯定终身难忘。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnRO20nyO1jJj55whFY0mOicr3QYCnPyrzrWNqo9fQ0PqStiafhiaQfOtHAFU7Wdt5e9BJwfjmiaGs1AA/640?wx_fmt=jpeg)

  

对了，不能漏了揭阳的美食，简直超绝，性比价超高，对比过潮州和汕头，揭阳的美食算是很划算的，人均20就能吃饱。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnOBYrbXRgu1KxiaJ9SZpxjy7hSMB7cgwu8Y4uJxOyyNEzwveuAFbgKIYcrCQO3GLIppdUD4Y4iazibg/640?wx_fmt=jpeg)
