迄今为止，广州周边我最爱的小岛出现了，比海鸥岛更舒服，找回生活该有的样子
====================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

假期就应该逃离城市，避开人群，终于给我找到广州周边最治愈的宝藏小岛了～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibQyfia81xmbHy1HzghzYC8WGvfF4AyCNEjFwibwDR3sjVF7zYdickFiaibgA/640?wx_fmt=jpeg)

  

广州1h直达阳光沙滩大草原，环岛骑行吹江风，江边露营看浪花，草地奔跑喂牛羊，找回生活该有的样子。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibKoaibiawvhLkz232pp3H26eAfvfdBzUra03wo18sGicHBTxBws5DZR3Tw/640?wx_fmt=jpeg)

  

这里就佛山平沙岛，元旦假期也不多人，游玩体验比海鸥岛好不少，超适合带上家人朋友一日游。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibMzDticofSpnrTQicpTZ7wpxDibOsVI5CdOxfvKiaOaLvzicQ168AZsX2Nqw/640?wx_fmt=jpeg)

  

自驾导航佛山平沙渡口，目的地有免费停车场，汽车也可以坐轮渡上岛。

  

去平沙岛只能坐轮渡哦，去的时候不收费，返程时收费，4元/人，40元/车。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibEIGaZokPSHcq8BSHM42kwLbnOTggzfpnweMibMic3JFkSWg1GILTrRibA/640?wx_fmt=jpeg)

  

可以选择直接开车上岛，适合游车河和江边露营，也可以把车停渡口停车场再上岛，租个电动车沉浸式体验平沙岛的慢生活。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibpShiavh2VPMTwtaxKeM1g6Aa40fwpqkKKZsViaHEtSjiaaIjIicXkHbbibA/640?wx_fmt=jpeg)

  

平沙渡口的景色美得像一幅画。

  

江面辽阔得仿佛是大地遗落的一面镜子，一直铺到视线尽头，与淡蓝色的天融成一片。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibFdlPeKHQhu3sgJ2MljaTTzcnqU8e4EqXicFb99iaOn3iazFub5FFY3H0Q/640?wx_fmt=jpeg)

  

阳光只是温柔地抚着江水，江面便成了千万片细碎的银箔，随着看不见的呼吸微微起伏。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibbG2UBlZibEia2yKfgQpYia3IcpBlAcF0bsAQj957mngSNMDZ8Ys3ZstnA/640?wx_fmt=jpeg)

  

对岸的轮廓是一抹淡墨晕开，几座厂房的烟囱静立着，白色的烟正从顶端袅袅地升起来。

  

江心的轮渡正缓缓靠岸，拉出两道长长的、渐次平复的水痕，行驶得那样安稳从容。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibTwYRShT12UDcu14KOa7WD4liaXQxt6aVk99zRl8cyicXG4dnRzxlV5Xg/640?wx_fmt=jpeg)

  

站在轮渡上，江风带着水汽拂在脸上，凉飕飕的，幸好阳光暖着后背，轮渡的汽笛偶尔鸣一声，悠远而苍茫。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibPC6tp4FicKkxPmXEbNLULMKWicuOx5lZtAPtHPMfTyicHoiboTMhTENwiag/640?wx_fmt=jpeg)

  

上岛往右走就能看到租车点啦，可以砍价哦，我们租的电动车是60元4小时，可以坐5、6人，还是很划算的。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibOmTU0gic3bIb2hzo4w3zicmuURpiaCw5O82en6woHKl1HZ7rr14iakM5Tg/640?wx_fmt=jpeg)

  

对了，平沙岛靠江的地方风很大，宝子们记得穿多一件风衣，别被吹感冒了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIiblQMLGiaW3VjiarfFH0bCNhVueKkX5NwOGNQ96XCTcQ8iaWk6tqxmGWMpA/640?wx_fmt=jpeg)

  

岛上有很多营地能露营，导航平沙沙滩边马场，汽车直接开到江边，这里可以骑马、开越野车和露营，还可以荡秋千。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibObPlJgN3eVu43cq1oGyLhJf4pG7HlS85aO5Rfntnqnj1MkibczGygmw/640?wx_fmt=jpeg)

  

露营地是村民承包的，有提供卫生间和水，收费是15元/人，岛上也有别的沙滩是免费的，但得找一找。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibWmnGrHFQnwveJubvAZsPFtdWsicZhrIh6aob0jc0nZgAVdib4HPvuicPA/640?wx_fmt=jpeg)

  

就算不露营，过来走走也很不错，岸边的落羽杉黄绿渐变，草地铺展至金色沙滩，蓝天白云下的浅滩有点像“小洱海”～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibm6IMvEccYCumkTCTFsygBy89Pia0YvuQwvo5SJ0o4ozFsDFO7rxNdmg/640?wx_fmt=jpeg)

  

这里的人很少，只剩下悠悠浪花的背景音，就连呼吸也不知何时，已变得和脚下的波浪一样轻，一样缓。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibvQOEYfI6qV03nIN1BMlkbcIT9VHCBicPkWRoFPX6ZSfPuffN94NibO4Q/640?wx_fmt=jpeg)

  

我觉得体验感最好的还是环岛骑行，一圈是10公里，开着电动车慢慢悠悠走一圈差不多2小时，路上的风景，流淌着与你相遇。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibj2hbCNZDF7LIKsz1qic6yG5cJ2RgEhfmtfWEF16OGGHOZrvia7Bhe9Qw/640?wx_fmt=jpeg)

  

路边的市集有浓浓的烟火气，蔬菜瓜果都是刚从田里采摘的，甚至还带着新鲜泥土的芬芳，价格还比菜市场便宜。

  

买了两斤菜心、一斤番薯干，刚好环岛路上边走边吃，美滋滋～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibOibVrzd5ribsGCc2XchLTAGV8uUqU5WuA0ib1Or9NUvyHSYBsiaxqDhhRA/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIib1Y164vcWWFj9r3NdNcxzOyej153s7JsicgYpM9MVDyRfmxfZuib6Qia8A/640?wx_fmt=jpeg)

  

一路上都在感慨岛上的生态非常好，数不清的农田和果园，随意睡在路边的慵懒牛牛，还有边吃边拉的潇洒小马，乡村田园风扑面而来。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibAx6kPvNwnTxtmlOe8Bt0HQdd45IaWlO5rLiboBd6Rjyjek7HIDTQakw/640?wx_fmt=jpeg)

  

现在是草莓和圣女果的季节，岛上有好多果园可以采摘，可以去田里“视察”一下成熟了没，再决定摘不摘～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibjOkz5Kf1NhDpUhOGqZK8T0qNc6CianN9xpcMrtCPAZdvLAiav3FUZzRQ/640?wx_fmt=jpeg)

  

路上还经过一个小农场，阿姨让小盆友免费喂小牛牛，他们超开心的！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibSp02el5pvyTsiaCbu5VUPNic9gd9edXN07o6DanzUm6pWvbNcZBaz2Rw/640?wx_fmt=jpeg)

  

没有门票，没有嘈杂的扩音器，只有阳光、青草、奋力吃草的牛牛，以及无比清脆爽朗的欢笑声。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibMWGBapibJia1sQ23UMdgCFJEEUniaGFQibiaoaVQibKHMVI2uUyoJb2vibDfg/640?wx_fmt=jpeg)

  

环岛骑行真的太舒服了，平沙岛的江岸，会以它最本真的开阔与淡然，给你一份轻松抵达的疗愈。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibCDiatiakNBtfofjWTh8jvP1X2JWbs1LlicfuUBLc8MFwNXKSbTJpsCfkA/640?wx_fmt=jpeg)

  

关于吃饭，岛上有农庄和餐厅，在平沙渡口附近也有好多河鲜餐厅（不用上岛），无需担心吃饭问题，也可以自己带吃的过来～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibIum33RVFeEzwXFuiccy9C4wp9icVZcY7rGU6OajdMMPRzrsmgib8oQjyQ/640?wx_fmt=jpeg)

  

来平沙岛游玩，不用想的那么复杂，渡口-上岛-骑行、露营、探索，就是这么简单。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibtfBXtviaKkaExlIUjg0iaJGWbpxkE2Wrv59uZ0LcCtPu7aovZ2PrUcMA/640?wx_fmt=jpeg)

  

你可以无所事事地度过慵懒的一天，看云如何从一朵变成一群，看江水如何潮起潮落，或者与不期而遇的小牛呆呆对视。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOljn2Z26aLEg8RVXAu0NzIibV30SpF16qGHovlWM6GDpDgqsjbSMMakbySoOwuEFf5bAicdvZAAnczQ/640?wx_fmt=jpeg)

  

这里的惬意，不在于拥有了什么，而在于可以放心地“不做”什么，心灵像那浅滩上的云影，只是安然地舒展和飘荡。

  

找个好天气，过来感受下小岛的慢生活吧～
