大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

万万没想到，在市区的华南农业大学居然是顶流科普遛娃圣地，逛博物馆、露营、捞鱼、喝酸奶，好玩到飞起，一天都玩不完呀～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HfDnwQd3cKAzPTrJrhazF89Ar1Kia6oW4BtQofPpjaQItQ8iazxFm5e0w/640?wx_fmt=jpeg)

  

周末还不知道去哪遛娃，华南农业大学值得闭眼冲，今天阿珍带宝子们华农一日游，有想法的宝子赶紧Mark了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HvuYCwybcPoa8VTyMmzZZ5XEXy7xHjtlMviaXDibd7ajT6gH1yJSv9BjQ/640?wx_fmt=jpeg)

  

进入华南农业大学第一件事就是预约，在学校公众号预约即可，刷身份证进入校园，记得提前预约哈，周末有时不好约。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HsHoHDWclObGFOK5om2LaTPEQKP8I3bc3jIict8UaibNJcFXAnuThdLAQ/640?wx_fmt=jpeg)

  

华农博物馆一定要去，超好逛又暴涨知识，完全免费需要预约，每周三、五、六、日开馆，别跑空哦。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HgQO9YbnEtIrqkia4F1ybtqLnDibtF9IEWjicpNYkibibD4SOgIibeDf8kH6Q/640?wx_fmt=jpeg)

  

华农大学交通很方便，我们乘坐地铁3号到达五山站A口，出站向右转就是学校大门。

  

自驾导航华南农业大学南门，提前预约到访车辆，校内停车位很多，5元一小时，很实惠呀。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HiaZhVQLWagVib4Mw9ZiaOPa1weCI7eE1wHJD7HLLfwacyjxW7macPGHLw/640?wx_fmt=jpeg)

  

校园地大景美，有很多好玩的地方，宝子们可以带上露营装备和捞鱼工具，逛完博物馆继续玩一天～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HbELRZykDrvjbiaqQpJiaRgIoNgaZZ4tjcbdjvKTbenlvVw2iaW9XrbFiaw/640?wx_fmt=jpeg)

  

上午进校直奔华农博物馆，虽然只有两层展厅，但是展品超级丰富有趣，几乎每个小展厅都有互动娱乐设施，小盆友在这里玩到不肯走！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HWvIKCBtbaymFg4CO8ZNu8PmtyhL3niad6ibibZQ0pVTYict5VT71ekRQiag/640?wx_fmt=jpeg)

  

周末上午10点半和下午3点半都有工作人员讲解，不想走马观花参观，可以掐准时间点过来哦。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HYnQU2nSUricGnCqEibpVKZFJ08RhSZgSia5NLt1XJztM9uZXazX5zuVdQ/640?wx_fmt=jpeg)

  

博物馆一层分为农业历史、农耕工具、土壤岩石3个展厅，二层分为植物、昆虫、动物、海洋、林业5个展厅，仔细参观需要3小时左右。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HFA0PsC8kF3fAV4vSrewjyRxKf9OZ9SQRoDEklr66ooe5aiatrTWFoMQ/640?wx_fmt=jpeg)

  

无论对农业感不感兴趣，这里都超乎想象，知识体系硬核不枯燥，特别是听完讲解后，知识暴涨呀～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HJ3n5aLcXFBxexMFScAicQlW8KlExoSicj6IeQUrgqeSfPyAnBPEFU6sg/640?wx_fmt=jpeg)

  

在这里可以看到比脸盆还大的灵芝，五彩斑斓的蝴蝶墙，还有被囚禁在琥珀里的史前昆虫。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HRPibKB9E1icbEa0f9iaBqY0voF6VK7gbXu5XtV01k8cgIbeIBzh5Fq0jw/640?wx_fmt=jpeg)

  

让我印象深刻的是这匹2米多高的温血宝马标本，挺拔俊逸栩栩如生，好像随时会冲出展柜奔腾而起。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3H6MyOs0APiaibzxxicOauxoY9oNr5ibXjB6ert636eE5PoyyN2bXu40wpPA/640?wx_fmt=jpeg)

  

还有世上最贵的荔枝标本，聪明的宝子应该猜到了，就是增城挂绿，仅有一颗挂绿荔枝树，每年的产量都在减少，十分珍贵。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3H8FiaJb5icv7Rcic7VmicC5XBd71ep0ibG5fXlmFHdKVT9eMaTnEag5ZwHVg/640?wx_fmt=jpeg)

  

逛到海洋展厅好像进了水族馆，各式各样的海螺排成精美的图案，各种鱼类标本悬浮半空，这里剥夺了海水的喧嚣，把生命最原始的形态呈现在我们眼前。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HVORe3FTBhH38z9CRq322LUmQlCmUgPVtNQp3YPGFKaianYaXMicTj6vQ/640?wx_fmt=jpeg)

  

上午逛完博物馆就差不多吃饭了，华农有5个食堂，也不知道哪个最好吃，我们挑了最近的绿榕园。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3H87u4ibHDcYrkAFU82qQo3KqdvjBwQbpJl9LVdVqSGDjWDvm4x617RAw/640?wx_fmt=jpeg)

  

二楼是自选快餐，菜的种类很丰富，直接到窗口排队点餐和付款，外来游客需要加收20%。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3Hpdb1PTm1iaqk6kwN3dLQbZvXRyIzMl9yOyNmOMSezrhVfsjYyLiaZYuw/640?wx_fmt=jpeg)

  

我点了三个菜收费20左右，阿姨给的量很足，其实点两个菜就够吃了，味道中规中矩，不难吃哈。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HkBqmdt1Yl9jz3kA9b106bib4bWiavcm400DOG4B5tWNgLEqMvAjHDY4w/640?wx_fmt=jpeg)

  

吃饱喝足就直奔教三大草坪露营吧，这里被称为华农“阿勒泰”，绿油油的草地超清新超chill～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HSIEeWibvDd7DXHVYKO9ppQQHAyToHDUTGMyfic8L1qJWNJ2sJeaSfk2A/640?wx_fmt=jpeg)

  

几乎是不由自主地找了块草地躺下，草叶稳稳托住了全身的重量，鼻尖萦绕着青草被阳光蒸腾出的独特清香。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3H2KBxRJwm2tpsvaibAiblq1L8EPMNaiblPibUMBcicYbaP57Z2RZcSU32txw/640?wx_fmt=jpeg)

  

耳畔传来孩子们追逐嬉戏的欢笑声，闭上眼让阳光变成一片温暖的橘红，所有思绪被清空，这份平静惬意快要满溢。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HRbMMLcfiazDJvZqUY1jGPIFK8McnvwbTPIJG7ibobyzIx2Nco5jI4zXg/640?wx_fmt=jpeg)

  

接下来还可以去华农湿地公园捞鱼，平静如镜的碧水湖，倒映着翠影与天色，湖里的小鱼成群结队，根本捞不完呀！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HNksrQddic0dAkYrcWibiaaCl7v4kyNH5JoCcV3uRE2JtKXFXyENVGukicQ/640?wx_fmt=jpeg)

  

相比起小盆友捞鱼，大人钓鱼更起劲，钓一会就上钩，嘴角都压不住了，光在这里就可以玩半天～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HGkGyiceu2jPUqmomZrZQvlyhdXJrYxicMic5HxibTO2iaFBpme2vj6icWFDQ/640?wx_fmt=jpeg)

  

来华农可别错过酸奶文化馆呀，点一杯奶茶或酸奶靠坐窗前，享受一个慵懒的午后。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HlicW8JiaGGXyBWfm5gKjR69bCy2ibYFks6jXX4QxZ3rNXR4NALvLCRniaA/640?wx_fmt=jpeg)

  

馆内还有一个小型图书馆，复古书架+暖色调灯光，超级适合阅读和办公，这里有提供插座和Wifi哦～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnU2NZVnr1iaFJDQ73rskj3HaDWWicMP2LyFJCGKhglu4ClWTJpe46aqia75nwQ1eicd61ia1hhN3uVptQ/640?wx_fmt=jpeg)

  

华南农业大学可以玩的地方还有好多，还有牛马吃草没去看，只能下次再去了。

  

不愧是市区遛娃天花板，找个好天气赶紧出发吧，这里不会让你们失望的！
