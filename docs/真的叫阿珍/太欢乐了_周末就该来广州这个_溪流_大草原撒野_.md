周末就应该来广州郊外的大草原撒野～

  

在黄埔知识城附近的洋田村，村口前面有一个沿着河涌建成的小公园，河边有大片大片的草地，在上面翻跟斗都行。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9Jbk2icmEkh3RYTpkzDOE2o7rWibicn5zyGF4a5A8HurNOAsfIfgAlMl4mOg/640?wx_fmt=jpeg)

  

沿着河涌蜿蜒曲折的绿道有好几公里，过来徒步或骑行简直不要太舒服～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbUdtgtyIkFx2TCSVia5AGYMfOrPmg8DQmj1KArpSK1EWSCjdBDLsqWfw/640?wx_fmt=jpeg)

  

这个免费的溪流公园可以烧烤、下河玩水、露营烧烤，不管是溜娃还是溜狗狗，都很不错！

  

我们可以乘坐地铁14号线到达镇龙北站C出口，再打车4公里即可到达。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JboL8EeRF2JXwYP3HPuF26vu8tH6X1cddaS6PJYUV7ccG4aUhsLyWXPw/640?wx_fmt=jpeg)

  

这里比较适合自驾，导航黄埔洋田村，在村口的牌坊旁边有免费停车场，不用进村子的。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbpL15T5K4PfFOqv4NKuNxMiacyq3K8Qvt7rXVnsXRrfiaDyKzRXzXjH8g/640?wx_fmt=jpeg)

  

停好车后往回走过桥，然后向右转再前行200米就可以看到大草地了，选择这边是因为靠近中间的公共洗手间～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9Jbth7pBjtrxgicjEJdCqETfudsPMhZtkK6OaexAas59kr9qq4GVR6SGlw/640?wx_fmt=jpeg)

  

这片宝藏溪流地其实是平岗河的一部分，这里有号称最美S弯的草上步道，在一望无际（夸张）的草原上蜿蜒绵亘。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbCcGSm0aQpt0oLR4k7l7DNqS7uxJfQ4xW6mFjaw1oqicqqsuqnGLm8Ug/640?wx_fmt=jpeg)

  

草原上错落摆放的大石头像极了正在吃草的牛和羊（想象力丰富），这是属于大自然的亲和力！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9Jbzb11sazeL92kXX3zqMhEB1STO7Wzfm7JG0T35AfQiavkeXMZUwTqhCg/640?wx_fmt=jpeg)

  

河道上还有一条弯弯曲曲的木栈道，两旁都是落羽杉，不过现在已经过了最佳欣赏季节，落羽杉的红叶都掉光了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbHxb9R93XznF2e4dP4MgUc1Zc8ibxUVLe3gY5kOCsp9LvofREDstPA1Q/640?wx_fmt=jpeg)

  

其实平岗河两岸的景色都很不错，河水澄清如镜，缓缓流过石板河堤，在阳光下显得晶莹剔透。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbFPMA3ibSialvZR2ErIqBxqvjVdSlia1IQDRSzpC5XPkncVaMAHopGiaiaWA/640?wx_fmt=jpeg)

  

夏天这里就是小盆友的玩水胜地，浅滩的水不深，冰冰凉凉的很舒服，里面大鱼小鱼全都有，能不能抓到就各凭本事了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbaDpKwFhQ1FDSDfZ8ISQib2ib8Wib8GDh4Nh7KZdRiaI4rXlTlibWWuUtZdQ/640?wx_fmt=jpeg)

  

我甚至还在水面上发现一只小乌龟，好像还是第一次看到野外河流有小乌龟，一动不动是不是睡着了…

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9Jb7p0eqEy0fGj5o4lzs47VVLPTj7Zgz2WbwstlT9jChhcXa1uT0rVyYA/640?wx_fmt=jpeg)

  

这边的草地很开阔，可以遮阳的大树不多，所以早上8、9点或者下午3、4点过来比较合适，光线更柔和，景色更好看。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbDIrXe3rZukAAMqeoMQkpxcFEMn82o9tAcEytPWxl2aQIrLTmbbJ4jw/640?wx_fmt=jpeg)

  

对了，这里没有小卖部，我们得自带水和食物，但有一点比较好的是可以叫外卖，要是啥也没带，叫杯奶茶边走边喝同样很快乐！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOn6SlYF2MqetuF2VIwics9JbnaKYDhmgtxgPPL8AKsXtRFHX32XCCvapGew6qVHicTgBWrLKhyrqKxg/640?wx_fmt=jpeg)

  

可能因为洋田村远离市区，所以周末人也不多，不用担心人挤人，从此周末又多了一个亲近大自然的好去处，Mark起来夏天过来玩水～
