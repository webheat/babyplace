不用去东涌！我又发现了广州这片“绝美”花海，不被打扰的感觉真的很好！
==================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

我站在花海中间，静静地什么都没做，却好像拥抱了整个春天！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZ91erH8oCPkFa55AwibNAE4NicIRIwHImhkFoG0DdyYtj4QNGHlwRXvrQ/640?wx_fmt=jpeg)

  

没想到龙归南村里面竟然隐藏着一片油菜花海，目前花花正旺盛，高低起伏的花浪好浪漫，犹如春日里的一幅油画。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZjwYrhhaye0qOmtuCic6ypOA47Er00ImPX1uUKDf5gcElSAzjG5MYX2Q/640?wx_fmt=jpeg)

  

最重要的还是人少，工作日基本没人过来拍照，周末人会多一点，但远不到人挤人的地步。

  

而且花海旁边有高地，从上往下很容易拍出置身花海的感觉，找个好天气赶紧过来吧！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZcoc0B7o9GNEwccAdLb5lbYTyYSx48McKwvibYnoAC3hZ3dhM7Ma4IGA/640?wx_fmt=jpeg)

  

我们乘坐地铁3搞站到达龙归站B2出口，定位孖（zi）祠堂广场，步行20分钟即可到达，也可以扫共享单车骑行，8分钟就到。

  

自驾导航孖祠堂广场或者周氏大宗祠，村里可以停车，不过窄路多，推荐公共交通出行。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZtNZu1ibO1Gz4iaLQHOd28Su6Dzazl5GVAxQqNZ9sdVPia7TbUOKgXr5Mg/640?wx_fmt=jpeg)

  

从地铁口出来穿过龙归南村，村里给我的感觉挺干净，和别的城中村不一样，人流比较少，也很安静。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZZo523jgaKFQGZv1FTXsXrpASBgictIErtiaarJWtK7Q61B5efaFiaC19A/640?wx_fmt=jpeg)

  

跟着定位走，最先看到的是周氏大宗祠，也叫孖祠堂，周氏大宗祠的建筑非常华美，把岭南建筑中的三雕两塑展现得淋漓尽致。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZG3GjmOwBtw2XrZKCsQ9SnO7eAzvpfA4DWdgNKBMOr5Qgs7HUGZk1Fg/640?wx_fmt=jpeg)

  

从孖祠堂广场往前走一点，顺着斜坡下去就是大片大片的油菜花海，当前开得最旺盛的是黄色油菜花，隔壁还有两大片彩色油菜花海，交相辉映。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZdMeObL218oDM4ZoyicrgcRGRMVDnheP0iakt9lS7zRibQgut7HjwEiaZNQ/640?wx_fmt=jpeg)

  

在油菜花海的周围还种上了一圈彩色格桑花，可以同时拍到两种花花同框，真的美哭了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZxBr7XEjnt0TSEaga3TxbT6Xs1524khIzJJ8dPfxZkWU9kHj3rv0Mpg/640?wx_fmt=jpeg)

  

这里️有专门进入油菜花海的小路，供游客下去拍照，田边插着的“龙归南村”灯笼非常有氛围感，建议过来和它们合个影。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZXoBfTyUWazxpDqTcX5MC5tAXib4Vg9toFjIX5qO9BzZcjVqRGHx8zPw/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZbD5Z9AWVUnaibn2XJLbNerSicVicoXgnKry1ib2mjxmaFI2AAab9jfjPwQ/640?wx_fmt=jpeg)

  

这边的花海很有意思，除了蜜蜂和蝴蝶萦绕飞舞，还有超级多小燕子在花海巡游，甚至时不时就有大飞机从头顶飞过，给花海增添多几分活力！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZ6hDBleGlibW6QPXFQBKWGA4XrONGXMOE8RibgqeuYTxB9PGEr9vLnTlQ/640?wx_fmt=jpeg)

  

拍完花海先别急着走，我们可以到村里逛一逛，在池塘边栖息着好多鸭子，胖乎乎的很可爱。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZcCVjwPPEZOmDy8LPf61RDlol2aib6LFur76aYncRCnWdqGDNMqhKyBQ/640?wx_fmt=jpeg)

  

沿着池塘往里面走，后面有个云青学舍和榕意学堂也超级好看，很容易出片。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZpgAa9TMpSPtEYfHcIiadakRn1PLyJ1H8oLSz9icSP0KVU4rWOugibnKuQ/640?wx_fmt=jpeg)

  

榕意学堂中间的大榕树非常壮观，它的树冠广阔无垠向四周伸展，像屋顶一样笼罩整个学堂，用超广角镜头都无法拍下它的全貌。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZXgkdDjgEKh8ibOKyN8Ric5KOTBtvStAr0ISq3fQ3DibzYye2KIhFZlHIg/640?wx_fmt=jpeg)

  

它翠绿的树叶也展现出蓬勃的生命力，树下摆满了石板长凳，还有栩栩如生的雕塑，坐在大树下享受这片刻的宁静。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZ0ZgO5z2Ax4ibickict2AkcdCbofibrryAElcI3m2NnmTBBNpdCHh7o0JBg/640?wx_fmt=jpeg)

  

一下子想起了小时候放学，在村口和邻居家小孩一起玩耍打闹的场景，突然有点感慨。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlQ1sMbZk0sslJ14iaX9kUEZJhLSvoEXiaL2jrIFnS8ibRRcR64nS2uW9ybq5Iia8ufG9LeqjmwgRBz4w/640?wx_fmt=jpeg)

  

就像这颗大榕树每年春天依旧抽出嫩绿的枝芽，可曾经在树下乘凉的人，却再也回不来了。
