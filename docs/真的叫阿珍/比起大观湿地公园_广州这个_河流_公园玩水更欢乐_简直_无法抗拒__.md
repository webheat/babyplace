比起大观湿地公园，广州这个“河流”公园玩水更欢乐，简直“无法抗拒”！
==================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

想必去过天河大观湿地公园的都知道，一到周末就超级火爆，想露营去晚了还找不到位置呢！

  

其实附近的黄陂湿地公园同样很适合周末出游，好像知道的人不多。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBz2ruoanRTWP63dpezNbLy76hIGh0RicWicmwaZ5WiaCP8Rp2dDqstHy4w/640?wx_fmt=jpeg)

  

长长的河涌连绵不断，溪水清澈见底，碧道两旁绿树成荫，还有嫩绿大草地，一不小心就走进了漫画的春天里。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBnv39y9PJVVMEHKB4kV6Zia0OUHUkQLPbMLl3au0KW8a4Gcw8EM6nDRg/640?wx_fmt=jpeg)

  

黄陂湿地公园依河而建，免费免预约，周围的绿化超级好，河的两边铺设绿道，可以骑行、散步。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBkP8D7RCvkib1XCFgbNFNzVXOL6ia2FHjqkLyCRb2ibupicQJTWqphOllVQ/640?wx_fmt=jpeg)

  

河边可以捞鱼、钓鱼、挖沙、捉蝴蝶、捉蚂蚱、放风筝、遛狗，自由自在。

  

岸边的草地很适合露营，躺在地上晒晒太阳，睡个懒觉，十分休闲惬意～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHB1g9pmkOvRuZT4DRjvnjwibWtl48K0eV2P82dIC1wSuWSHxnMPO9qnIA/640?wx_fmt=jpeg)

  

而且公园就在地铁口超级方便，乘坐地铁6号线到达黄陂站D出口，往前走50米右手边就是河涌绿道了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBakEb46RcwZ9CSJg2NhW7F1AkVODFW8w4asra7dWQzeYQd1pI984WUw/640?wx_fmt=jpeg)

  

自驾导航黄陂湿地公园，在联华路两侧都可以免费停车，有很多人停，下车就看到绿道了，过来这边露营很方便。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBysphWibDFib9WgTMopgx1uz2ytrq1NZTvibD2KiaMRiaia1VNYA0iaL4w5OpQ/640?wx_fmt=jpeg)

  

公园范围的碧道大约3、4公里，慢悠悠走一圈一个小时多点，但我看地图发现沿着河涌走，还可以一直走下去。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBqhoHVRIlgiagRtiaIa9ZGoaANmZkVXGLO3QKs0JjwafwCkRHImh2gGvQ/640?wx_fmt=jpeg)

  

第一眼看到这里就被种草了，河涌很宽大，岸边的草地青翠欲滴，溪流波光粼粼，充满了浓郁的自然气息。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHB2AfaLcNcWTpVfkd7h0uFESZeFUyfYEnpaHCJ0PLzqjyWMic1kYcHcLg/640?wx_fmt=jpeg)

  

靠近地铁站的溪流比较浅，水质也很清澈，河里有好多小鱼小虾呀，感觉随便捞一捞都能抓到几条。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBGVJWC4dYx8e6IaG47egWAM5oHiaSEccUlAZSOBhC7fonahhFicHw6KVg/640?wx_fmt=jpeg)

  

还没到夏天已经有好多家人带着小盆友过来玩水捞鱼了，有条石块路可以穿过河道，这一段是最热门的溯溪点。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHB6V7ghicS8ZRiauf2g93nNmEXGX8h9x0vOhZOLic8PriagEroCcxficib275w/640?wx_fmt=jpeg)

  

小盆友抓到小鱼乐开了花，只是站在旁边看他们抓鱼都觉得很欢乐。

  

别说小盆友了，大人对这种小河流也是毫无抵抗力的，夏天这里肯定是顶流溯溪点。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBX5M4yI4kNEx7h9vH0R0Hq3VvFg8khd9eAo6HNAGUCdd5LIPiciahWBYw/640?wx_fmt=jpeg)

  

沿着碧道一路上都是郁郁葱葱，微风徐徐，地铁口就有共享单车，扫个单车绕着河涌骑几圈，心情好到飞起！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBIDP3Y4aEtVjSic3x9UcVibVH1AibWa8vZOtHxh7USrmop6b65E5ReEQxw/640?wx_fmt=jpeg)

  

再往前可以看到人工湖、圆拱桥、九曲桥等景观，同样被绿意包围，岸边还有不少鲜花点缀。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBtyjsW7jDfT5Q8sDxtQ10hyMoYqqcerZzhtGDWS0hOQcwyjTV77zGlQ/640?wx_fmt=jpeg)

  

在这里露营最合适不过了，和大观湿地公园一样可以使用明火，车停路边，把装备拉到河边草地也就几十米，公园中部有公共洗手间。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBL3bmkTMf8Kjq7z5ib38JZK61QhKkpk3XFuhRN1iaibNJYWZTou7WXQkeQ/640?wx_fmt=jpeg)

  

一路上有各种卖水果和小吃的摊子，附近也有小卖部，甚至还可以点外卖，过来游玩不用担心没吃的。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHB2gJc3BTXxZCKSQ7mnPeEfkTPcALWDagiaTeTCEibV3yyH58cbrOTDic3Q/640?wx_fmt=jpeg)

  

黄陂湿地公园特别适合一家大小过来游玩，搭个天幕或者帐篷，爸爸在河边钓鱼，妈妈带小盆友去玩水，玩累了就回来吃东西～

  

别问我怎么知道的，在这里遇到好多家庭都是这么分配的，哈哈。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl3fdY9jSZ1UU92JPMF4mHBtUdImfQ3KRWZtfZWzysgTfqmkul0W1zHuLbRqvCSyK3HDkerFbCR5A/640?wx_fmt=jpeg)
