一隅山岗，半城风景，广州这个“绿野仙踪”太治愈了，免费徒步遛娃秘境，地铁公交直达

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

周末就应该放下手机，走进山林，让呼吸跟上自然的节拍，让心跳变成山石的脉搏，把城市的喧嚣调成静音模式～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUINc74h1VNHJsXG0Yj8y9yn5icJQ4JaaXuDm0NMg4LqiaHicnrGEthUiaeIQ/640?wx_fmt=jpeg)

  

99%广州人不知道，在增城新塘还藏着一个轻徒步治愈绿境，浓密的树冠隔绝尘嚣，留下清风与鸟鸣二重奏。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIZdwTCJCBaYRHpR77dOh3pHTX3SL0LOnlO1wH2c9XBj41mUsHmN5QlQ/640?wx_fmt=jpeg)

  

漫步在蜿蜒山径，空气像洗过般清冽，看阳光洒进丛林深处，看落叶在空中旋转，这里不拥挤、不催促，只有宁静包裹的慢时光。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIeA7ic72AFAcraBpwPZSwMrzVCGibadsu5zBGAyKzicl8icEwCVtqyQTnpw/640?wx_fmt=jpeg)

  

这里就是四望岗公园，被誉为广州东部越秀山，位于广州市新塘镇国际牛仔城附近，松林丹荔山花烂漫。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIklzB7BjRib9auxb6Utb5UpRmqA7GUNyYCbknia7VbDq8e0G6c9ELgPKw/640?wx_fmt=jpeg)

  

曾是明代尚书湛若水（甘泉先生）培育尚书怀荔枝的地方，见证了新塘从古到今的沧桑与辉煌。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIR6StZsic1v6IMBsJjaoFIibpicaZmo1QqOXEvOceyx3ou9XXibfoxocm5Q/640?wx_fmt=jpeg)

  

原本以为是个普普通通小公园，没想到这么好逛，整个公园被翠影环绕，没有摩肩接踵的游客，没有嘈杂喧闹的叫卖声，周末也能独享这片清幽自在。

  

这里很适合徒步散心、遛娃拍照、跑步健身，对宠物也十分友好～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIYB0iaY5XgUxxqZjkUpl3yav3xxZEJxdov3hTvESKwfv3AriaGiaCFJORA/640?wx_fmt=jpeg)

  

我们乘坐地铁13号线到达白江地铁站D2出口，换乘571B路公交到达新塘总站（四望岗公园），公交站旁边就是公园。

  

自驾导航新塘四望岗公园，目的地有大型停车场，车位充足，3元一小时，前2小时免费，非常实惠。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIibVEqyhmvblguQ28f0mh096hvh8bnia32lP9dI4vb6AibBlNLvOice9rKQ/640?wx_fmt=jpeg)

  

四望岗公园全天免费开放，园区种满了樱花、紫荆花、黄花风铃木，每到春天一路繁花似锦，现在则是绿野仙踪。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIRWjZjTv6MxzoIKMGkhV5FwGqwsG27iaAiajhdOjDXPQZuKEEMhguzYww/640?wx_fmt=jpeg)

  

有几条路线可以上山，我们从正门进入步道，跟着沿途的指示牌走就对了，不会迷路的哦。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIHJYIfVrElyWzDhobUgdNV4IXhtjicicmcpU7wXpYCza3RjtTOBLzvCkQ/640?wx_fmt=jpeg)

  

从山脚走到山顶的四望阁，慢悠悠半小时就可以登顶，一点都不累，全程基本都在树荫底下。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUI3gYnb7SS93jaxhuiaubR0lF6LO4miaKansu6cM1trpIrq8voKlSxzlwQ/640?wx_fmt=jpeg)

  

有登山阶梯和平缓步道两种路线，设计合理坡度不大，而且无论阶梯还是步道都很宽阔，很好走。

  

四周都是满满负氧离子，大口大口地吸氧，五脏六腑都被滋养，清新渗透每一个毛孔～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIJIiatttloy5Zp9wsZZFl3PGWbGB3t6bib7hqHKY9SXGyOrkxUKplHsBA/640?wx_fmt=jpeg)

  

山脚和山顶都有公共洗手间，沿途有造型唯美的小凉亭和长廊，没有看到自动贩卖机和小卖部，记得自带水和食物哦。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIphdhlBqBzymPmhkZ3yAiafoI8ISspz456GH8YZpaqaQtVBSkgOenOMw/640?wx_fmt=jpeg)

  

公园景色最好的地方在山顶四望阁，这是一座三层中式阁楼，黑瓦朱柱，既有岭南传统建筑风格，有融合了现代简约元素。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIw0qOGWibINmynFtqrVnVOmgFydSR8umYnEiamrxdgBxibO9M0CzleQPkA/640?wx_fmt=jpeg)

  

重点突出一个“四望”，我们登上四望阁，四周毫无遮挡，可以远眺东江，四望新塘镇中心城区建筑，还有远处的田园风光。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIZ7JiaIgMmsmTyNo2Abgib1RceILzjzAJxSTxpLkia1iac82LB8vhNiau6Pw/640?wx_fmt=jpeg)

  

当目光翻越城市重重屋顶，思绪早已飘成天边的流云。有些出逃，无关距离，深呼吸一口气，在心里种下一片森林。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnoJkjLs12PwJH8iaOBj4XUIAibGqibnDCcQTJSPevpGv8tkziaIj0yheSeDUkCEQ9OVQdKP8LuBWjJnQ/640?wx_fmt=jpeg)

  

周末想避开人潮找地方遛娃或放空自己，那就来四望岗公园走走吧，这里绿意融融宁静深藏，只待与你来一场心灵的“深呼吸”～
