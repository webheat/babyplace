# 客服功能配置指南

客服功能已集成到代码中，以下参数需要你逐一补充，补充后即可正常使用。

---

## 必填参数

### 1. 企业微信 corpId

- **填写位置**: `src/config/customer-service.js` → `corpId`
- **获取方式**: 登录 [企业微信管理后台](https://work.weixin.qq.com/) → 我的企业 → 企业信息 → 企业ID
- **示例值**: `ww1234567890abcdef`
- **说明**: 这是企业的唯一标识，所有客服功能都依赖此 ID

### 2. 企业微信客服链接 (extInfo)

- **填写位置**: `src/config/customer-service.js` → `extInfo`
- **获取方式**:
  1. 登录企业微信管理后台 → 应用管理 → 客服
  2. 创建客服账号（或使用已有账号）
  3. 进入客服账号 → 获取「链接」或「小程序客服链接」
- **示例值**: `https://work.weixin.qq.com/kf/xxxxxxxx`
- **说明**: 这是用户点击客服按钮后打开的会话入口链接

---

## 容灾配置（普通微信客服）

企业微信客服作为主通道，普通微信客服作为降级通道。当企业微信不可用时，用户仍能联系到客服。

### 配置步骤

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 用小程序管理员扫码登录
2. 左侧菜单 → 功能 → 客服
3. 点击「添加客服」→ 输入要绑定的个人微信号
4. 该微信号会收到邀请确认，确认后即生效

### 生效逻辑

- 用户点击客服按钮 → 优先调起企业微信客服（需 corpId + extInfo 已配置）
- 如果企业微信客服调用失败或未配置 → 自动降级到普通微信客服
- 普通微信客服的消息由绑定的微信号在微信公众平台后台或第三方客服工具中回复
- 代码侧无需改动，`<button open-type="contact">` 已集成在客服悬浮按钮组件中

---

## 配置文件位置

```
src/config/customer-service.js
```

当前内容（需替换空字符串）：

```js
export default {
  corpId: '',      // ← 填入企业微信 corpId
  extInfo: '',     // ← 填入企业微信客服链接
};
```

---

## 验证步骤

1. 填写完企业微信 corpId 和 extInfo
2. 在微信公众平台后台绑定客服微信号（容灾）
3. 运行 `pnpm run dev:mp-weixin`
4. 在微信开发者工具中打开任意页面
5. 点击右下角绿色悬浮按钮（"服"字）
6. 应弹出企业微信客服会话窗口

---

## 降级链路

```
用户点击客服按钮
  → 企业微信客服（corpId + extInfo 已配置）
    → 失败 → 普通微信客服（open-type="contact"，需在公众平台绑定客服微信号）
```
