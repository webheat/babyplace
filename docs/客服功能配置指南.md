# 客服功能配置指南

当前客服设计有两个互斥出口，由配置决定启用哪一个：

- `official-account`：认证服务号客服系统，当前启用
- `enterprise-wechat`：认证企业微信客服，待企业微信认证后接入

```
微信认证服务号客服消息
  -> uniCloud HTTP 云函数 babychat
  -> 立即返回 success
  -> 后台调用 AstrBot /api/v1/chat/sync
  -> 微信客服消息接口主动发送回复
```

当前先调通 `official-account`。企业微信出口先列入 TODO，不在当前小程序入口调用 `openCustomerServiceChat`。

## 前端配置

配置位置：

```
src/config/customer-service.js
```

当前配置：

```js
export default {
  activeProvider: 'official-account',
  officialAccount: {
    enabled: true,
    cloudFunction: 'babychat',
  },
  enterpriseWeChat: {
    enabled: false,
    corpId: '',
    extInfo: '',
  },
};
```

规则：

- `activeProvider` 只能二选一：`official-account` 或 `enterprise-wechat`
- 当前保持 `official-account`
- 企业微信完成认证后，再把 `enterpriseWeChat.enabled` 设为 `true` 并切换 `activeProvider`
- 切换企业微信时，需要补齐 `corpId`、`extInfo`，并在前端实现 `uni.openCustomerServiceChat`

## 云函数

- 云函数目录：`uniCloud-alipay/cloudfunctions/babychat`
- HTTP URL 化路径建议：`/babychat`
- 用途：
  - `GET`：处理微信服务器 URL 验证，返回 `echostr`
  - `POST`：解析微信客服文本消息，立即返回 `success`，后台异步发送客服消息

部署后，在微信公众平台服务号后台把服务器地址配置为：

```
https://<你的域名>/babychat
```

## Astrobot 配置

配置位置：

```
uniCloud-alipay/cloudfunctions/common/uni-config-center/astrbot/config.json
```

支持字段：

```json
{
  "baseUrl": "https://your-astrobot-host",
  "apiKey": "your-api-key",
  "timeout": 120000,
  "wechatReplyTimeout": 30000,
  "wechatToken": "与微信公众平台服务器配置里的 Token 一致",
  "officialAccountAppId": "认证服务号 AppID，可留空回退 uni-id web.oauth.weixin-h5",
  "officialAccountAppSecret": "认证服务号 AppSecret，可留空回退 uni-id web.oauth.weixin-h5"
}
```

说明：

- `baseUrl`：AstrBot 服务地址，不要带结尾 `/`
- `apiKey`：AstrBot API Key
- `timeout`：应用内聊天可使用较长超时
- `wechatReplyTimeout`：后台等待 AstrBot 回复的超时
- `wechatToken`：服务号回调签名校验用；生产环境应配置
- `officialAccountAppId` / `officialAccountAppSecret`：客服消息接口发消息用；为空时读取 `uni-id` 的 `web.oauth.weixin-h5`

## 小程序入口

小程序里的 `<button open-type="contact">` 用于打开微信客服会话。用户发出的客服消息由认证服务号客服系统进入 `babychat`，`babychat` 立即返回 `success`，再由后台任务调用 Astrobot 并通过微信客服消息接口发送回复。

应用内 AI 聊天页仍使用：

```
src/api/chat.js -> uniCloud.importObject('babyplace-chat')
```

`babyplace-chat` 用于 App 内聊天，不负责微信服务号回调。

## 验证

1. 上传 `babychat` 云函数。
2. 在 uniCloud 控制台为 `babychat` 配置 URL 化。
3. 在微信公众平台服务号后台配置服务器 URL、Token。
4. 发送文本客服消息，应收到 AstrBot 回复。
5. 如果无回复，先检查 `astrbot/config.json` 的 `baseUrl`、`apiKey` 和 `wechatToken`。
