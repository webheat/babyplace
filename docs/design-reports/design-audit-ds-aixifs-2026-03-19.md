## 发现问题

### FINDING-001: 占位符文本 "pending" 可见 [HIGH]

**类别**: 内容质量
**位置**: 资讯热点列表

**问题**: 资讯列表项显示 "pending" 占位符文本，表明后端数据未完全处理或前端未正确处理时间字段。

**截图**: 见 `homepage-clickable.png` 资讯区域

**建议修复**:
- 检查 `publish_at` 或 `created_at` 字段的格式
- 确保后端返回有效的时间戳
- 前端添加 fallback 处理无效时间

---

### FINDING-002: 评价数格式混乱 "0.0 0 条评价" [HIGH]

**类别**: 内容质量
**位置**: POI 卡片

**问题**: 评价显示为 "0.0 0 条评价"，格式混乱。应该是 "0 条评价" 或 "暂无评价"。

**建议修复**:
```javascript
// 当前
`${rating} ${count} 条评价`

// 建议
count > 0 ? `${rating} ${count} 条评价` : '暂无评价'
```

---

### FINDING-003: 字体使用系统默认 [MEDIUM]

**类别**: 排版
**位置**: 全局

**问题**: 检测到字体为 Times New Roman，这是系统默认字体。uni-app 应该设置更合适的字体栈。

**建议修复**:
```css
/* 添加到全局样式 */
body {
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
    'Helvetica Neue', Arial, sans-serif;
}
```

---

### FINDING-004: "小程序优先展示" 标签对 H5 无意义 [MEDIUM]

**类别**: 内容质量
**位置**: 地点精选区域

**问题**: 在 H5 端显示 "小程序优先展示" 对用户无价值，建议条件渲染。

**建议修复**:
```vue
<!-- #ifdef MP-WEIXIN -->
<text class="tag">小程序优先展示</text>
<!-- #endif -->
```

---

### FINDING-005: 信息密度较高 [POLISH]

**类别**: 间距与布局
**位置**: 首页整体

**问题**: 页面内容较紧凑，各区块之间的间距可以稍微增加以提升阅读体验。
