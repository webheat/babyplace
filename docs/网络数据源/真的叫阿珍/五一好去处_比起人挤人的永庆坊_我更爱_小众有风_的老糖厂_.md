==============================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

五一出去玩，对于“i”人来说，最受不了的就是人挤人…

  

假期想找个有趣的地方安安静静逛一逛，强烈推荐番禺这个“小众”紫坭糖厂！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6bEmjgVjPP5yK6yhIJ9YzIqUePSU4X80Evy6F2Bz17HbticZoicUzVd5Q/640?wx_fmt=jpeg)

  

第一次来就好喜欢这里，泛黄的苏式建筑，斑驳的红砖墙，锈迹斑斑的大铁门，瞬间将我拉回了那个充满工业气息的年代。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6eRibibsdiaBOaVSssoTtSicFm7Mib7N95BqV3Zs3LVHicqbwwE0S17dtneQg/640?wx_fmt=jpeg)

  

增城的1978电影小镇大家去过没有，番禺紫泥堂创意园和它有点像，也是旧糖厂改造而成的。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6wXscZAKgatSYoDZqkUNsld1nhhB3bDw5ia9bkrZCfYz5ZtOIZciaTbFQ/640?wx_fmt=jpeg)

  

不过紫泥堂的面积更大，分为好几个区，想要仔细逛完整个创意园得3、4小时。

  

虽然经过改造，但还是保留了原有的历史气息，园内旧厂房的废墟工业风拉满。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6dOE9K9mf0Z9FLjjq9ShZibW3FR6eT2t7HyJAqa9icqC2E3plicJ1ia0tCQ/640?wx_fmt=jpeg)

  

精致的涂鸦和浮夸的雕塑又把这里的艺术氛围推向高潮，即便周末游客也不多，天气好时还能在园区江边看到绝美日落。

  

这里适合散心、拍照、遛娃、遛狗、骑行，园区甚至还有房车营地可以露营。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6ibveRwpey7KJloShmhG0lYlvLfPsFKOQM1uxNHt6AKTLQrjkG6U4Cmg/640?wx_fmt=jpeg)

  

紫泥堂免费免预约，开放时间09:00-17:00。

  

乘坐地铁3号到达市桥站B出口，转番67路公交到紫泥村委站下，步行5分钟到达紫泥堂。

  

推荐自驾，导航番禺紫泥堂创意园，园区内有停车场，3元一小时。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6mEPgX1l94xSHZItKLf7CibPvDQSYGm9dFunD9s0ZeklWxez2xcc6Gpw/640?wx_fmt=jpeg)

  

靠近北门有一排黄色苏式旧房，还有几家很艺术的咖啡店和茶馆，这里拍照特别出片。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6P8J633KeuYmrQgOBKkOXQt48MkoXIicicX5sM8m8EYt1ibKMAa2MeLM0g/640?wx_fmt=jpeg)

  

逛累了过来喝个下午茶，呆坐在窗前晒着慵懒的阳光，翻开一本残破不堪的书，纸张的陈旧味，带我们找回过去那段旧时光。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6ibHVtgRFjCTwLZlIuAB94kr3Kv9QRTbOMVTFtUKvNcCEwAJp2iaGsWWg/640?wx_fmt=jpeg)

  

好多人只是逛了前面的苏式建筑和咖啡馆就走了，其实紫泥堂还有好多有意思的景点。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS62WN3iazI0uSgFWP3fLN74DWY2aLq3mE9RUUVvorHCpO9wNopAyCBNYA/640?wx_fmt=jpeg)

  

像华漫英雄私藏馆、陶瓷美术馆、紫泥堂历史博物馆、3+3艺术区、手艺人图书馆、咏春广场、电影影棚等等，都值得深入走一走。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS65Oib3ajTxPLjLiaDblDc4icxB1YlhSv7QVAKOR6iapWxJMibwZgic0tm187w/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS67ZPHSDU9tvfawwSxIMzp12QW8g4uv4QaCicB8Qwo2GtdJ0LKUCXuicRQ/640?wx_fmt=jpeg)

  

我很喜欢在废墟厂房的穿梭，和平时游山玩水不一样，这里更有一种探险的感觉。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6fe8q7Gde4stJiaHZUL8qT3OUiaRHicGIpPd96rBt4hqbuCl5vpMdaAKUA/640?wx_fmt=jpeg)

  

从废旧厂房的窗户望进去，废墟中只有白色圆顶建筑完好无损，有点像电影取景地呀。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6CrNbEqgul5XoTJsKeA63jPbicHKwCia4VJnAiaicWibcuUka0pSlnjT9JvA/640?wx_fmt=jpeg)

  

途中还遇到一辆蝙蝠战车，真的太帅了，细节做得很到位，如果能开起来就完美了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6soaF00kyyKdCEnX3RjvXwYJxmoKZq8rAt7SlTpjiadAuqo2c1gINtkg/640?wx_fmt=jpeg)

  

穿街走巷还偶遇一只喵星人，看样子好像不开心，一靠近它就走了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6fNuOHsmjYOXlvbg5fQEbojOfj9vkhNOoWp0DXPpiaFMiawGKAXoibPQiag/640?wx_fmt=jpeg)

  

结果一转角就看到超大的“大橘为重”墙壁涂鸦，越看越像刚才那只喵星人，只是没这么胖，哈哈。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS62TKroCYhYqOwxqO55HqT3dDvWM1ugD9ibiaWzYsMzicgibUhdhqvaWOuPg/640?wx_fmt=jpeg)

  

园区的街头涂鸦和钢筋水泥碰撞很有冲击力，也少不了各种奇特的雕塑。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6Pv3MkPWTTbvXLvQXic3XHL6t2X264Ge6RQqp6WvSDS6YDNHMOABdHMQ/640?wx_fmt=jpeg)

  

这个半身人抱着马头的雕塑没看懂是在表达什么，可能是我的艺术细胞不够。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS642B3ibicw9ibicqUjnCy9JNATCIpXQq4yGeiba6MAOvprV0DGMw6bzIGXNg/640?wx_fmt=jpeg)

  

类似这样有趣的雕塑还有好多，漫步在园区就像寻宝一样，逛久了也不腻。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlpINtZXzicKW448R2mGDnS6Q4BJSIoeIYCXgIOmdrPxJMWgGECgGA6sa5vCpp7rkVBScsAVb4OWyg/640?wx_fmt=jpeg)

  

趁着五一假期过来紫泥堂拍照打卡吧，还可以顺路去附近的沙湾古镇喝个双皮奶，又是充实有趣的一天！
