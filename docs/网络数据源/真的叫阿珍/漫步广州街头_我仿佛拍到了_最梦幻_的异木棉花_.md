漫步广州街头，我仿佛拍到了“最梦幻”的异木棉花！
========================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

漫步在广州街头一不小心就会走进二次元，这颗绽放在十字路口的超大异木棉树，仿佛是打开二次元的大门。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlJef45DAhooe9Uic50zrX0ib9b4TnRLUMbpzoLrhibPLN6SC7iaibdVwY8r5Lq7l0ibI3zQ6WeBT9hnBpg/640?wx_fmt=jpeg)

  

绽放了一树的粉色幻想，一靠近就好像走进了宫崎骏的动漫世界，在这个繁华的闹市街头显得如此耀眼！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlJef45DAhooe9Uic50zrX0ibhjGStD7E705CXHBylx8AOUM3kqLHXZ7wzXvoqhbbVOCjjQyGaJ57mQ/640?wx_fmt=jpeg)

  

这颗超大的异木棉树在广州应该是数一数二的吧，就在白云区京溪附近。

  

乘坐地铁3号线到达京溪南方医院站C出口，导航至“蔚来体验中心（广州京溪）”，步行15分钟左右就可以看到。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlJef45DAhooe9Uic50zrX0ibfK8YxprfC0mscyaa9liaRibmqfp2aJhDK75XCh1DsFcSup4IR6Ik89YQ/640?wx_fmt=jpeg)

  

有刚好在附近的友友可以过来拍照，这颗异木棉树真的太美了。

  

离远远就能看到粉色的花瓣随风摇曳，过往车辆和行人的目光都被它深深俘获，只见过一眼就很难遗忘。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlJef45DAhooe9Uic50zrX0ib7zCsjurTMGErw34MgFE257u3roly9bVsib78uvhroJrKGywKKOQ5IZw/640?wx_fmt=jpeg)

  

推荐下午3:00后前往，下午的阳光更柔和，适合拍出梦幻的效果，推荐穿浅色的衣服，比如jk或水手服，搭配粉红色的异木棉可以轻松拍出动漫感，超级出片的！

  

切记路口交通状况非常复杂，在拍摄角度的时候请注意安全哦～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlJef45DAhooe9Uic50zrX0ibhXL69XRXeyicCwOh3pibFZA7jpyN5ianz5888gxPOrEn01aIg3qKot81g/640?wx_fmt=jpeg)

  

突然觉得在广州生活太幸福了，在平凡的日子中，不经意间也能遇到令人惊喜的感动，唯有美景最抚凡人心。
