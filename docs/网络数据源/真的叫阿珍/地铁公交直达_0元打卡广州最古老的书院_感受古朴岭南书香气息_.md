广州其实有非常多不为人知的美好景点，不一定非要去人挤人的热门景点。

  

阿珍觉得位于黄埔萝岗的“玉岩书院”就是一个人少景美的好去处，环境清幽古色古香，比“陈家祠”还要古老。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpOn6LGddp4z4vLHIcOg7bXMavN4k1kb2dW9xywRQo95qc3JfOBIgp5g/640?wx_fmt=jpeg)

  

玉喦书院（yan）始建于南宋，距今已有800多年历史，是广州现存最早的古书院之一。

  

书院依山傍谷，建筑群上下两进，横向分东西中三座，结构紧凑，设计精巧。

  

这里不仅是书院，还融合了祠堂、寺庙、园林，是岭南建筑中独特的存在。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpmFMB1OUmXgwzCxXLHQQmyibiadekgTtTzwSezovSbTu0APXthWIS9F9A/640?wx_fmt=jpeg)

  

我们可以乘坐广州地铁6号线到达香雪站F出口，然后打车前往。或者乘坐公交365A路，坐4分钟到萝岗站公交站，步行600m。

  

自驾的话直接导航玉岩书院，门口前面可以免费停车。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpRxkpoeOV0fOfiaicw0SrLpxWy5Is2ibn81fN8UwwUn0lyJpvLQy4dGbsw/640?wx_fmt=jpeg)

  

玉岩书院的开放时间是08:00-17:00（16：30停止入园），每周一闭馆，进行维护和休息。不用门票不用预约，门口登记一下就可以了。

  

玉岩书院不算很大，自下而上慢慢参观欣赏，2个小时左右就足够了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpjs880HJHP417FooBorbkgmMceicWIpUQ0UpvicUXAPK9A7lKozAjDNDQ/640?wx_fmt=jpeg)

  

这里连空气都弥漫着岭南书香气息，匾额雕刻处处是文人雅士留下的过往，有朱熹，文天祥的诗词，有郑板桥的字画，能够更加纯粹地感受到历史沉淀感。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpIA488b3wFqxVpzFex4ThibGHDYicFwJBS6iahsBGoGiaNicicl00QYJ5slyg/640?wx_fmt=jpeg)

  

余庆楼

书院的门楼，雄伟壮观，是进入书院的第一站。进入书院之前要先爬上石阶，非常有仪式感，这座楼的天井有七个屋檐，形成“七檐滴水”，既能排水防潮又方便采光，不得不佩服古人的智慧！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpRIIiaquuibRTEqETc7MPMgrabibiada1wxeoO7j5KotM0HbQr9pDFw7vmQ/640?wx_fmt=jpeg)

  

玉岩堂

位于余庆楼二层等高的台基之上，主要供奉先祖钟玉岩。堂内还挂有朱熹手迹的“忠、孝、廉、节”匾额，体现了儒家的核心价值。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpDq8Aicy86FKZYL1Bib9zib7W1svicQ6GOb8N3OZB7kntdnuoTHUfBQa6ww/640?wx_fmt=jpeg)

  

山高水长亭

爬上后山，一个别致的亭子建在山岗上，被绿树环抱，亭内还有一块清朝两广总督张之洞的诗文碑刻。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWpHVrTpoafCykvSKSdLiaKnArOB7cntvFIXv9o2cdYmXGVkcIAKJkIa3w/640?wx_fmt=jpeg)

  

游玩路线

  

余庆楼-玉岩堂天尊堂-观音殿-洗心池-山高水长亭-候仙台-文昌庙-招隐亭

  

注意事项

1、建议穿着舒适的鞋子，因为书院内有许多石阶。

2、由于书院位于山林间蚊虫较多，建议携带防蚊液。

3、雨天时石阶可能会滑，请注意安全。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnUe1egn8tux5KBIMg3EbWp2DRNkx6JVKvyCTbKNdgibz7dRZqDAXI65cz9rN1Nib54CfIffNTs1kZQ/640?wx_fmt=jpeg)

  

不知道为啥来这里的游客特别少，但反而让整个书院显得更加宁静深远。

  

十分适合周末过来闲逛、散心、拍照打卡，旁边的香雪公园冬天可以赏梅花，也是广州著名景点之一。
