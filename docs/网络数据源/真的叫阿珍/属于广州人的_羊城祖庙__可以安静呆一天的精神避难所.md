最近广州的五仙古观太火了！

  

翻新修缮5，6年，终于重新对外开放，吸引不少游客前往打卡，其中不乏本地老广。

  

五仙古观藏在闹中取静的老城区，始建于明洪武十年（1377年），距今已有600多年的历史。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9RF7GcVveKt0ibhm2QbwbqiakYiapGV5bQsibT2f4AHTNkPibNv9SfBbpiaYaw/640?wx_fmt=jpeg)

  

相传古时有五位仙人骑着五只口衔稻穗的仙羊来到广州，把稻穗赠予当地人，帮助广州富庶至今。离开时留下足迹并派五只仙羊守护广州，是广州别称“羊城”的起源。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9Ry9ceXaFPpfKY1XCQwOF9tedB6ZMGHPoWdAokdoq3wib3TF5k8rEB8jA/640?wx_fmt=jpeg)

  

五仙古观位于广州越秀区惠福西路，乘坐地铁1号线或2号线到达公园前站A出口，再步行900米左右即可到达。

  

开放时间：周二至周日9:00-17:00（周一闭馆）门票：免费、免预约

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9RfvWiaiccBKYlm91beUGpIRiaJiaSPiaXrrPrRYcdEHCXOE8rvDan0IAq2fg/640?wx_fmt=jpeg)

  

五仙古观整体不大，一个小时就可以逛完，重新修缮后的古观红墙绿瓦，午后的阳光照射在浓艳的红墙上，真的太好看了，拍照完全不输农讲所！

  

  

头门：五仙古观的入口，门上大匾有清两广总督瑞麟书写的“五仙古观”四个大字，古朴庄重。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9RMqXOA2tGenhcmicibC9acxKbl5YzILIPv1FhiaZ77G391IxocOfTd7xAw/640?wx_fmt=jpeg)

  

后殿：后殿上盖绿琉璃瓦，正脊两端为回纹饰，中间为两条相向倒立鳌自，正中脊刹是宝物饰，是广州现存最完整的明代建筑，殿堂内供奉着五仙的神像。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9RibG3ufuuabBEzBppvkML0yVhwfRoibaZEZNUQj5JuZMCyUmpApBzMKAg/640?wx_fmt=jpeg)

  

岭南第一楼：楼基用红砂石砌筑，上建栋宇巨檐，构成一座轩敞的楼台。二楼挂着一口广东最大的青铜古钟，也称“禁钟”。

此楼不仅具有很高的建筑艺术价值，还是广州历史的重要象征。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9Rc4UG8YVT4aUr9ico6THQJbibkCwAd7Aic2H3FXPCoCOfib7A6PE5oAxOLg/640?wx_fmt=jpeg)

  

仙人拇迹：后殿东侧有一块红砂岩，上面有巨大的脚印状凹穴，古人认为这是仙人留下的脚印，称为“仙人拇迹”，是观内的一大奇观。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9Rj4jabzPnY69qjJia5dg2icwn07QuRrTcm8YPe2dbQvOSVicnL4d76OLlg/640?wx_fmt=jpeg)

  

石麒麟：大门口保存有一对用漱珠岗火山岩刻制的石麒麟，这是国内十分罕见的珍贵文物，造型生动形象，具有很高的历史和艺术价值。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9Rouia3wdtwLLYomp5YSicDg7TrHibsj45Iotvic7ibyOud5I4oicn7DBosslA/640?wx_fmt=jpeg)

  

碑刻：五仙观内保留有宋代至清代的碑刻14块，是研究广州历史的重要资料。这些碑刻不仅记录了五仙观的历史变迁，还反映了广州地区的历史文化和社会风貌。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9RfxGNBY31zB5B1Fg3X9w0U6joUAlql93KmFFvuJSVEOelWh6YY51l5Q/640?wx_fmt=jpeg)

  

五仙古观不同角度，有不一样的建筑之美。红墙，绿瓦，凉亭，十分适合参观休闲拍照打卡。

  

古观旁边就是南粤先贤馆，馆内除了记载从古到今南粤名人伟人的事迹外，还有不少互动装置可供体验。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnO9U7dqV5peUlXTtwtFR9RKpn2O632Z0RGiaEvyYpcar40HPCprMwsnHkibmIdiaWUzDQOibVEicGj1HQ/640?wx_fmt=jpeg)

  

周末来一场岭南历史探寻之旅吧，既能休闲放松，又能领略岭南历史文化魅力，广州这片土地太有趣了。
