比起海珠湖，我更喜欢广州这个免费公园的花海，美得“肆无忌惮”！
===============================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

广州被称为“花城”果然一点都没错，到哪都有超级好看的花海，阿珍又找到一个欣赏花海的宝藏公园，太适合周末过来休闲放松了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6ha8kH7iaZxLC1Js6j1HLhg1RuUdE6kSGrhyHhTibdN3GiahCVPstnUIGibDw/640?wx_fmt=jpeg)

  

这里就是新塘的万田生态公园，不仅有6000㎡的超大花海拍照打卡，还有草坪可以户外露营，甚至还能在公园里小溪流玩水，而且免费免预约很不错。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6harbibZOlxZ5vMaRNtueLJSfZ4GzKAhuuJiajZdL3cUa5fNFIjt1jTNibUA/640?wx_fmt=jpeg)

  

可惜没有地铁直达，乘坐广州地铁13号线到达官湖站A出口，打车过去15分钟。

  

自驾导航新塘万田生态公园，就在荔新公路旁边，公园门口有免费停车场，附近就有洗手间。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6ha5LbEjm1iaLIwUiajibGd3KHNujwJRuGVibfsBSfhQUOdKQFkqPfOufTxuQ/640?wx_fmt=jpeg)

  

这里周末人气挺旺的，一踏进园区就看到高、中、低各层次的植物，树木、灌木与绿草花卉争相斗艳。

  

一条蜿蜒的小溪流特别引人注目，溪水清澈，倒映着蓝天和周围的树木，显得格外宁静。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6ha2tiaEicib96hOChLlmt45yhibnV3ic1wKNXuDINY2XrzD0JlOkPicJKTOLnw/640?wx_fmt=jpeg)

  

这地方有点像之前介绍的“凤凰湖项目部”的缩小版，小溪边有大树遮阴，夏天带小盆友过来玩水肯定很快乐！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haVM8CLCE4hcsIRYQBKYdqDgCDBw9ACJ5SWXaCdGibX6EP0icZYxmMRWbw/640?wx_fmt=jpeg)

  

公园里种了好多黄色叶子的大树特别好看，阳光下温暖又耀眼，周围还有大片大片的草地适合露营，带个帐篷或者铺张野餐垫，直接躺平，真的很惬意～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haIbSk4HxQmgSROicvic65aMc8y4Swju6kkBFYb1ibhQfLLUb7sedQDZ0gw/640?wx_fmt=jpeg)

  

我还发现这里专门建有用于慢跑的塑胶跑道，适合喜欢运动的友友过来锻炼身体，还可以顺便欣赏花海。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haDpQKjk6UPiaxBYzTlXSjFXFDEeqo3veLG1tDN4sQ0Lcsmud8Yyhic4CA/640?wx_fmt=jpeg)

  

说到花海，我们沿着公园绿道往万田水库的方向走就可以看到了，就在水库前面，好大一片波斯菊花海！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haz1nribWYlwuC8Sm8p1DtNiaA3WfbiaZRe5JzOS2RttvHSneYzue2G0YwQ/640?wx_fmt=jpeg)

  

和海珠湖公园的比起来不相上下，但这里的人没有海珠湖那么多，想怎么拍就怎么拍，穿浅色衣服和花海更搭哦～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6han25pLUxp1AsQEdRIfkIz2v5ibufbicBCcVB4AED7FfibC69ncghopePNA/640?wx_fmt=jpeg)

  

心地善良的人对于成片的花海完全没有抵抗力（臭美呀），远远就看到一片粉色在跃动，恨不得赶紧冲入这片粉色世界。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haOrSGOAAIwsPBZH2UetHu8qweAB4gnicYckV6UITO5DvHcEGbnibUBfbw/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6hazeYok0N0rHVAN0H6T9OVyxfWLJxDwubu4hfN48I4R1kQHicA2W1GQJg/640?wx_fmt=jpeg)

  

每一朵花都像被精心雕琢过，粉色的花瓣在微风中轻轻摇曳，黄色的花蕊如同星星般点缀其间，散发出淡淡的芬芳。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haHkUMAfvrqfAjdG0LFE7bcTXKIetglg8XIT9oYbQbo1W8IqI6Cw1J9g/640?wx_fmt=jpeg)

  

花海周边的小路旁边是水库的水槽，走的时候要小心点，别光顾着欣赏花海，踏空就麻烦了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6ha2OaCablkhJvWuTFwcw9ujdl2Coc5MScA2kJwLTW6phvGDRYhc8AVdA/640?wx_fmt=jpeg)

  

花海走上去就是万田水库，面积不大但是风景不错，沿着大坝走，吹吹风很舒服。

  

看着白云飘在蓝天中，也很有日系feel，以后不用专门跑去金坑水库拍照了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haGaobSjxhBUPdLUTXib76toOSEltr1HLw5oNicLPBJ4qiaogZybL87N0lw/640?wx_fmt=jpeg)

  

来之前感觉万田生态公园平平无奇，来过以后觉得这里很宝藏，太喜欢这里啦，人就应该多待在没有天花板的地方！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOneB37eYGt4bIoKUWvgZ6haZUEQ7XiaGWpofmLfuY0p5NqZ7jwSJicnj6ib56f9obj901COLVohnpDkQ/640?wx_fmt=jpeg)
