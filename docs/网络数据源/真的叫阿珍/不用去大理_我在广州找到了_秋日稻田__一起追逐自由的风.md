不用去大理！我在广州找到了“秋日稻田”，一起追逐自由的风
============================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

谁懂最近广州天气的含金量？

  

蓝天白云晴空万里，阳光暖而不晒，

  

气温26℃舒适宜人，周末不出来玩太浪费了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUfWmCzxIKVhROXHhCPrufZFh7a3dwicYopLvwAugwPiaCOw0PVBicdJyQA/640?wx_fmt=jpeg)

  

阿珍强烈推荐过来增城看“风吹麦浪”，最近增城的丝苗米稻田公园已经变成一片金黄色海洋了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUe8oKDKaNCuYFutMbTouicYBWZpEmUcibEZGBwE7Iic8TO04IQom9lysibg/640?wx_fmt=jpeg)

  

走在稻田间的道路中，清风吹过，

  

眼前泛起一层层金黄色稻浪，

  

空气中还夹杂着一丝丝稻香，

  

只需一眼你便会爱上这里！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwU3icTjiar1m8RQTDuswC1JtTicSMN3zdlk9TWiccPFWMfiaEUK0bVodWKMMQ/640?wx_fmt=jpeg)

  

去没有天花板的地方，追逐田野间自由的风。

  

广州的“秋”，被我在这里找到了。

  

轻而易举就拥有大理喜洲同款金黄色稻田，景色真的太治愈了，心情超好的！

  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUhH9wfjdYEtxyySGElMrhYS1Mdjs6phKwl0N7jSeUcfgc9zh7sN0Igw/640?wx_fmt=jpeg)

  

我们乘坐广州地铁21号到达朱村站B口，打车或者骑行（15分钟）前往稻田公园，无需门票，不用预约，全天开放～

  

自驾导航增城丝苗米稻田公园，直接停在路边不挡道就可以，看到有空地也可以停。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUTpZVW1wW3UkBribbIdnWPGxQuj80m1O0NvkicCNQrjeGLictibIEEaWetA/640?wx_fmt=jpeg)

  

记得选晴天过来哦，稻田金黄色的美才能淋漓尽致体现，建议自带水和干粮，这边没有小卖部。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUMdHdaauibN2ibfXY98sNeCaWqenHQPYByCqs9NyMbv0C0LeJxXIsOHWQ/640?wx_fmt=jpeg)

  

其实带上露营椅，坐在稻田旁边，吹吹秋天的风，看稻浪一层一层，那种深入触觉的美，真的好惬意。

  

田间道路也可以骑行，公路上的车比较多注意安全。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUqvVp7K5CRAAWSrmOSp7VjIWkJOia1n3anILYHfD5aYQ7zQZDd1aRwtg/640?wx_fmt=jpeg)

  

大人带小盆友过来也非常合适，可以放风筝，还可以乘坐小火车游稻田，9元／1人也不贵，带小朋友过来玩，强烈推荐过来体验一下。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUSOmWyoibZsdicUodKwqNGDb8tutCdZibXkD2I4Kk9ygJCG0z98Th3vMZg/640?wx_fmt=jpeg)

  

一节车厢可以坐一大一小，绕着稻田巡游大概15分钟。别说是小朋友了，就连大人也能旅途中找到久违了的童真。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUibSoAUSiaZO6psQ994wZBODkF9T4vXGIzulicbvkS2n6y2hYHNbxd9tibA/640?wx_fmt=jpeg)

  

返程时顺便可以去尝一尝本地人经常去香宾鸡饭，就在朱村地铁站C口。

  

一煲小份的丝苗米鸡饭好像是78元，鸡饭端上来鸡肉和米饭是分开的，鸡肉鸡味很浓，丝苗米饭渗满鸡油，吃起来超级香，不会踩雷。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUfOElXlujxAKXibvorD4kYia3ZUqNENT8RYuA0PQFW8CfmYSrdjHIcxVQ/640?wx_fmt=jpeg)

  

原来增城不只有荔枝呀，还是中国丝苗米之乡，若没有亲眼所见，根本想象不到广袤的稻田带来的冲击力。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmNuDdiaVnBYoDtwhvbJVOwUgulHYuGhKhB4UeNpvOiaLJ2jH0z0MX1NBAl5DZAOk7VUMwF2N0QxFfQ/640?wx_fmt=jpeg)

  

听说过两周这里的稻田就要收割了，想过来感受“风吹麦浪”的友友得抓紧了，这里拍照巨好看！
