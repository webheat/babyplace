广州也有自己的“那拉提”，黄埔这个免费“溪流”露营地美哭了！
==============================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

谁说冬天不可以溯溪露营烧烤，阿珍发现了位于黄埔知识城的绝美免费露营地，号称“广州那拉提”。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icauMeEnQdSBdedxS2lEFgUqZIeKtmJuFCTC56OzoTroj2zUO6MU1KoCEA/640?wx_fmt=jpeg)

  

沿着小溪流一路的景色真的很好看，特别是在午后阳光照射下，有种远离城市的不真实感。

  

这里非常适合露营、散步、遛狗、溯溪、捞鱼、抓小螃蟹，地方很大，找个晴天过来真的美翻了！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icau8kXm52VRviaC7rXFOee3VSkdsvHxia1vFz0kWicTwdicWs8miagwJQERvDA/640?wx_fmt=jpeg)

  

我们可以乘坐地铁14号到达何棠下站A出口，打车或者骑行前往，定位“凤凰湖项目部”。

  

推荐自驾，导航黄埔知识城“凤凰湖项目部”，快到目的地时有一段泥路崎岖不平，过了这段路仿佛进入了另一个世界！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icausmgUoIavhaYC9CH1libUASicB0cjQS3Nx6iaryDdXsf7aAtVgllhPYDHQ/640?wx_fmt=jpeg)

  

把车停路边，不挡道就可以了，或者经过凤凰湖项目部前往开，那边也有位置可以停车。

  

刚到“凤凰湖项目部”就可以看到小溪流了，这里其实是一段龙湖古驿道，景色超美！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icauQnfdwyDJyAr2VzBNMsucYee1RicoM1evCnGNKWfxlPd08mbofMR4YNQ/640?wx_fmt=jpeg)

  

刻入脑海的小溪流潺潺流淌，溪水清澈见底，沐浴在阳光中碎银闪烁，宛如一条银色的绸带在山间田野间蜿蜒穿梭。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icaulch63zDc10oWVr93Blr8fLSDNYoALEoZZhIbc76tpNZkFIFIg7ND7w/640?wx_fmt=jpeg)

  

细看之下，你会发现小鱼儿欢快地游走在造型各异的石头间，一旦有人靠近它们就四处散开。  

  

这一条小溪流一眼望不到头，应该有1、2公里长，两旁是平坦的大草坪，这里超级适合露营烧烤。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icaulutosdIdUFBbxy6Vk957gLYI2AWxUDr1NqJIsC4fMfnaMGpZRAIqUg/640?wx_fmt=jpeg)

  

而且绿道中间还有一间干净漂亮的公共洗手间，把最关键的问题也解决了。

  

过来露营要带走所有垃圾，不要往小溪倒东西哦，还有记得要带驱蚊水！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icauYqv6lmN1uW9a0nTEKZCiaC6iaxndfWIH1vymXxUQWiaaJ8pFy2Gea4OHw/640?wx_fmt=jpeg)

  

我好奇小溪的尽头是什么，沿着溪流漫步，一路上发现了红色落羽杉、黄色连翘树、绿色兰花树，五彩斑斓。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icauUQjlKQWp0yTayx5H7H2oeDfX31TyibI3cNXk3NADRgZDcR1Wz0MEibnA/640?wx_fmt=jpeg)

  

溪水带着山间的清新气息，滋润着两岸的花草树木，靠近溪流的草地分外翠绿，让整个驿道都充满了生机。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icaueobYQo5udibTqw63G45PIbfFDcYTh4Hjh6iaMJwYC5EIu9ia5Fm40ZBTg/640?wx_fmt=jpeg)

  

这一段溪流绿道被郁郁葱葱的山林包围，看着溪流缓缓流动，听着鸟儿啁啾婉转，一时间竟然忘了自己身处繁华热闹的都市。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icau3GdAJxeqPf3MeTWSpryH22prVBsUagxXss9vnR96gSNM83sWlsBmSg/640?wx_fmt=jpeg)

  

途中遇到了很多大人带小盆友过来捞鱼，午后的气温不凉也不热，好多小盆友脱了鞋子就下去捞鱼，在这个冬天竟然找到了夏日的气息。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icautICwZCacptty4icBrAhxWlqJkUSQgvy1tOSUwYoibQMHWqiaPwBDIia23w/640?wx_fmt=jpeg)

  

他们踩着石头跃过小溪，时而用手去抚摸溪水的清凉，时而捡起石头往小溪里扔，溅起的水花如同星光点点，我想这一刻他们是最幸福的！

  

一路上的风景怎么都看不够，走走停停，心情很舒畅。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlbx2ARrV5naXUJqbsh6icau1E2qtpibNd8z1icMfwY1OEAP5LBZEJIThtyEXJAPkjMZib4GZQIVtb5Mg/640?wx_fmt=jpeg)

  

来到溪流的尽头原来是一个小水库，还有不少鸟类在这里栖息。

  

我想在等前面那段泥路修建好，这里肯定会成为周末顶流露营地！
