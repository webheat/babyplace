天啊，我找到了广州市区最适合“躺平”的森系公园，这该死的松弛感！
================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

大家周末都是怎么度过的？

  

我肯定是到处晃到处逛，之前介绍了很多游山玩水的地方，有的友友觉得太远了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYudXZ1gfgpY7e2YAJ7uEceRV6fgNXO07W9dPWuziaKM1KqgyoIXYyDibA/640?wx_fmt=jpeg)

  

其实广州市区同样有好多宝藏公园，特别适合周末放松心情，像在老广心中地位非常高的天河公园，阿珍觉得这里超适合“躺平”！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYGYkQaNSiaP2ic1a4oJWzkG8MibygVoCt61F2yGHkEMfsBO63Ee4z7vjLQ/640?wx_fmt=jpeg)

  

来过之后才知道，原来平时在公司做牛马的时候，外面的世界是这样的景色～

  

来这里找到了这久违的松弛感，找一片大草地彻底躺平，让阳光洒在身上，暖洋洋的好舒服。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYvgASq1ZVKiaiaibBwuibl1ib2XnKMefrwdm2lDVCJeLdjr7WgDVV9VQPBtA/640?wx_fmt=jpeg)

  

带着柠檬桉香气的微风轻轻地吹，心里的坏情绪一下子就被吹走了～

  

春天的天河公园，被绿意和生机霸占，走到哪都是郁郁葱葱。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYyLDgGhf0nlwaZy9rOcHm5ibgOfnxvpdE930FcHWCGcTsLj9mrjlxAgg/640?wx_fmt=jpeg)

  

园内有乔木、灌木、花草、棕榈、竹子等100余种植物，好喜欢阳光穿过树梢光影斑驳的氛围感，很温馨。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYAu4icyQgPMteiauM0yniagBNoW6picnAERsKLBlE8umiaChKcr1qEtIXic6w/640?wx_fmt=jpeg)

  

这么美的天河公园不仅免费免预约，而且还地铁直达，乘坐地铁11号／21号线到达天河公园站E1出口，往右边走就是园区。

  

自驾导航到天河公园北门停车场，前3小时内，5元一小时，车位不多建议早点到。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYibYjEqUH8ib0zhtuVheY9zB0icceQ0fib6GP2b3h9cQ0cEvhIDic06ib0h6A/640?wx_fmt=jpeg)

  

天河公园说大不大，说小不小，单纯绕着公园走一圈1小时多点，但公园内部还有很多好看有趣的景点值得探索。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYs7hWjEficE8kEVHxEaU8lFyIOBddedQCNTxV9ND3V525gd6tuvsSHKw/640?wx_fmt=jpeg)

  

可以按照这条路线走：

  

缤纷步道广场-台地花园-粤秀园-森林石阶-粤晖园-湖边步道-翠竹广场-粤韵长廊

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WY3iciaQICOiaUOEmoHj8Huia0HOvDdiaIiakdibiaGy9w8vicOFm5QTPicHib7Mqgw/640?wx_fmt=jpeg)

  

一踏入公园浓厚的生活气息扑面而来，这里人气也太旺了吧，不管你是什么年龄段，都可以找到属于自己的小天地。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYHY62gESHEHrrxdPYy1jSevXH6YWrvm8DClM2hc8bDCnEOCh2Dwl0vQ/640?wx_fmt=jpeg)

  

这里可动可静，适合散步、跑步、遛娃、露营、摄影、唱歌、跳舞、约会，体验都特别好。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYfwyo8K7j9criajnuD0q7WaRfwdSvznjDKGqKWsxUFYTRZ9eeibO2fSnA/640?wx_fmt=jpeg)

  

公园里面还有儿童乐园，有滑梯、攀爬网、挖沙、传声筒、蹦蹦床等等，小盆友都在这里玩疯了，家长们也很开心。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYicHC1ruPxODEv4hQIYuNibhbrDk54jSzHPSOOgmKr4jwiaPo1EoJfwxTA/640?wx_fmt=jpeg)

  

如果喜欢安静点的，就往翠竹广场那边走，那的大树张力十足，高耸直立，苍劲坚毅！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYeibLF1Zbu9iak4eCO9d5F1gm64EicZ09TzpL1nvW57XXQCyFPaKl4QZ2g/640?wx_fmt=jpeg)

  

遇到一位大叔在树下打太极拳，站在圆形的地砖中央，每一拳都很到位，颇有点太极宗师的意思，哈哈。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYajOa0k2RdMSxOz2CzRjo56W4r8ibcibicrxw2C8y5gibVk5uWGmDs31lNw/640?wx_fmt=jpeg)

  

不管是唱歌跳舞、吹笛子、玩摄影等，路过的人都习以为常，来这里就应该尽情的释放自己，没有任何负担！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYr7DxfiaUYpWBbdq16IxnBTooGCYezs3Pq0P16qQwQKAYt7oelhbppFg/640?wx_fmt=jpeg)

  

公园里还一个很精致的粤晖园，极具岭南特色的凉亭伫立在碧潭间，四周磅礴的绿意将其包围，石板桥曲径通幽。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYLqWSiaRnds9WibRnfHylma17Sz2q98iasniaV5y4ctuU1G3E9MAJiaEJCNA/640?wx_fmt=jpeg)

  

这里的一草一木，一砖一瓦，都散发出古典韵味，我在凉亭里可以呆坐一天～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkcAJrCqvuic5FeOpYegI8WYCdt7xv2EVz1fcSZzDTIWdgpr4adNw6ItnVSjjlph5yMOtYdf0KpYug/640?wx_fmt=jpeg)

  

有人觉得天河公园很普通，但我每次过来心情都巨好，对森系公园毫无抵抗力！

  

工作忙，压力大，偶尔过来公园“躺平”一下，可以快速恢复能量哦～
