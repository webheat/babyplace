在贵州，这个被低估的小众古村落，是我今年去过最冷门的地方
============================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

在人杰地灵的贵州，“隐藏”着这么一个古村落，它仿佛一颗被掩埋在茫茫沙地下的稀世珍宝，静待有缘人路过揭开它神秘的面纱，而它那特有的魅力与韵味将深深吸引每一位旅客。

  

在这个古村落，你找不到一丝丝大城市的热闹与喧嚣，这里的每一寸土地，每一块石砖都留下斑驳的历史痕迹，无需诉说便能“听”懂它的古朴与宁静。

  

它就是位于贵州省安顺市的——鲍家屯，一座拥有600多年历史的明代古村落，先祖鲍福宝奉朱元璋之命戍守鲍家屯，其子孙在此聚居繁衍至今，已经传承到23代2000多人。

鲍家屯的规划布局相当奇特，呈“八阵图”布局，具有浓厚的军事色彩，展现出鲜明的屯堡特色。

  

走进鲍家屯，沿着蜿蜒曲折的石板路一直走，一块块大小不一的石砖堆砌出来异常平整的一面面墙，仿佛是古人在跟旅客“炫耀”自己的巧夺天工，用手轻轻触摸这些墙壁，穿越古今的对话就在你的指尖进行着。

在路上遇到身穿民族特色服装的当地居民请不要惊讶，无论时间长河再怎么流逝，他们永远保留传统的习俗与纯真。

  

未等到你靠近，他们已经远远地向你招手，热情地欢迎你来这里做客，仿佛你就是他们许久未见的老朋友。

鲍家屯的生活节奏异常地慢，慢悠悠地散步，慢悠悠地席地交谈，慢悠悠地喝茶扇凉，似乎进入了一个慢动作的世界，殊不知这才是生活，我们在大城市那是快马加鞭地生存。

阳光穿过云层洒在路两旁的古民居上，光影交错让村落的历史韵味更加浓厚，一阵清风拂过夹带些许泥土的芬芳，那种直入心灵的轻松感，从视觉到触觉，再到嗅觉，层层递进让你的身心都无比宁静自在，仿佛尘世间的一切烦恼都与你无关。

如果你在4，5月过来，就能亲眼目睹这黄色海洋般的油菜花田，这些黄莹莹的“浪花”随着清风一浪又一浪的摇摆，与大自然这般亲密接触，是我不曾有过的体会。

  

身在花田中，我拿出相机拍了一张又一张，“贪婪”地要把这美景通通占为己有，根本不想放过任何一个角落，直到好友搂住我的脖子将我“拽”走，但我心里早已和自己许下约定，明年花开之时，就是我归来之日。

⭐️交通指引

位置：贵州省安顺市西秀区大西桥镇的鲍家屯

自驾：直接导航到“鲍家屯”

⭐️当地美食

八大碗：包括扣碗、红炖肉、鸡辣子等，色香味俱全，是鲍家屯村宴请宾客的美味菜肴。

鲍家屯红米：非常特殊的一种红米，吃起来香甜，据说营养丰富。

鲍三妹山药面条：以山药为原料制成的面条，口感很劲道。

屯堡霉豆腐：看起来不好吃，吃起来不会停。

还有马烧腊、烤小肠、烤鱼，这些屯堡美食都值得品尝。

如果厌倦了人山人海的商业都市，那么来鲍家屯一定可以让你感受另一番宁静祥和。
