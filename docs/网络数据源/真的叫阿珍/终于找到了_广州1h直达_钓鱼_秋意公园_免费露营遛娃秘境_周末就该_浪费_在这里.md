终于找到了，广州1h直达“钓鱼”秋意公园，免费露营遛娃秘境，周末就该“浪费”在这里
=========================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

东莞这个秋意公园应该是我见过最棒的钓鱼地了，大人和小盆友一人一张折叠凳，在湖边排排坐，他们的背影都透出一种松弛感～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y89k2tOTpjo7hzJ3jZsPSsM4GXpjnJyTghtlYnXSicYm4M6kCPD4icmtLw/640?wx_fmt=jpeg)

  

小盆友们甩出小钓竿，动作非常老练，应该没少过来这边钓鱼，小手紧紧攥着钓竿，那份专注严肃的样子，连后脑勺的头发丝都写着“认真”～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8VibW6ppY9moosfEjzNzQ4woNuPup3qj17hkORlSu18UXb9JKPCtq78Q/640?wx_fmt=jpeg)

  

湖里的鱼真不少，而且还有“大货”，看着他们钓了一条又一条，这条鲤鱼大得连水桶都快装不下了，大人上扬的嘴角都压不住了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8LOMtGGCd86jRiacLlLZibPDbseUjelgorGJQX9vlMPI9mLUfdu7W3GMg/640?wx_fmt=jpeg)

  

粗略数了一下，坐在湖边钓鱼的大人小孩起码有2、30人，而且这里的景色也太美了。

  

湖面倒映着天色云影，偶有微风泛起淡淡涟漪，公园的落羽杉将积蓄已久的金红毫无保留地倾倒在湖水之中。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8sLELJiaibwAiak5U7v9iauWYb0dvpqE7vF46mTMyzo8BuAFQskdWbibjK2A/640?wx_fmt=jpeg)

  

只要待在这里几分钟，松弛感便从四面八方包裹而来，来自温润的空气，来自落羽杉的绚烂，更来自那份“无所事事”的正当性。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8WqCeLe1Im4HzPicgcr9n3KydbDN7rsAOsd5e6tNibzupSAeGvVhGFAAg/640?wx_fmt=jpeg)

  

这里就是东莞香遇走廊公园，不用门票，也不用预约，广州市区1h直达，搭乘公共交通工具过来也很方便。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8FHxwib9SnmaMk94KgsVyRJJtiaCusAnTjRHNDoMNIfKpzX4j8mTiaO77Q/640?wx_fmt=jpeg)

  

除了钓鱼，香遇走廊公园还很适合露营、遛娃、骑行、徒步、带宠物、拍照、赏秋，可以满足对美好周末的一切想象～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8rwJDvXz8obqvjK54ibUDprAeR3CdWfHRib48dLEO3VkV00OMXPfcqUfw/640?wx_fmt=jpeg)

  

我们乘坐广惠城际线到达东城南站，换乘43路公交到达机关二号大院站下车，步行15分钟到达香遇走廊公园。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8KnqZ1U7UszdD7yiaC3LMD9wBKSPgia0jwuQuAIxADZzWvtCEgdDkCkLw/640?wx_fmt=jpeg)

  

自驾导航东莞横岭村，进入牌坊之后，继续往里开，停在村尾的牌坊附近，2元一小时，横岭村也有烧鹅哦。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8IBibufrLSNNzkicxW4jT7jD82gjxLYvFlPRO4WBMCBC9cvtsNYB30k6Q/640?wx_fmt=jpeg)

  

往村尾牌坊走出去，可以看到进入公园的小门，走到分叉路口会发现一个亮闪闪的大包包，往右边就是香遇走廊公园。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8f2b8VITcZLfUGSYrHsXquqkibQ9sXOz24B6JibeQVIPWu2o9Z7Uk8ZoA/640?wx_fmt=jpeg)

  

公园面积很大，我们这次只是游玩了二期，通过人行天桥可以前往一期，那边还有香遇百花园，但二期已经足够玩了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8dN3sSs0l5eNSTOibV6XRP1VEDRiaI7zOAlUItFL1Kx4t6b8XJFftCB6A/640?wx_fmt=jpeg)

  

园区有水天一色的大湖泊，绚烂似火的落羽杉，平坦柔软的大草坪，一走进来就感觉很chill。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8A34TE7y0qe6kmxHicmDxmeQSDrQ8qbic9ibrLYyLhMLMdp2aLFoID4m6w/640?wx_fmt=jpeg)

  

靠近一期那边还儿童游乐园，有秋千、滑梯、攀爬、跷跷板、独木桥等，足够小盆友玩很久了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8lRgbasfP0WUlLJY4Zq2dlKfuOBztibywFElWchptAZyqEeFia6WmZFZA/640?wx_fmt=jpeg)

  

最惬意的还是露营，湖边落羽杉林和大草坪都是很棒的露营地，铺个野餐垫直接躺平晒太阳。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8O7xI7annsZ3KsyE2f21RibbT7uPVUpeWnYIZPerOzM8sliccZUgEgfKA/640?wx_fmt=jpeg)

  

或者去亲水栈道那边扎营，在落羽杉下一边喝茶一边钓鱼，美滋滋。

  

这里没发现有吃的，可以自带水和食物，也可以叫外卖，都很方便。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8tFt33viaAlaaz1KyzsODKAOBnvNKJQDL8iavCFhF8XEvmNDUrIEiaADyg/640?wx_fmt=jpeg)

  

最惊艳的还是落羽杉，比别的地方红得更快，基本7、8成已经进入金黄橘红的状态了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8hcB6hOMAreAJkCicialtMLR6Pn54zuuwx4hVnJuBLPg8SEn42EVWLFNw/640?wx_fmt=jpeg)

  

湖边的秋意氛围超浓郁，现在这个色彩过来拍照恰到好处，随便怎么拍都好看！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOkLb3gEBzrnfdhl6ib9jR5y8IynBEvtW6aSs1iaX8dCKmgFE2rQvq3FYGs64RW6bz4dq3XDrpv5cyhg/640?wx_fmt=jpeg)

  

很多公园都不给钓鱼，香遇走廊公园不仅景色很治愈，而且对钓鱼很友好，看到他们这么开心，我也想去买鱼竿过来试试呀～
