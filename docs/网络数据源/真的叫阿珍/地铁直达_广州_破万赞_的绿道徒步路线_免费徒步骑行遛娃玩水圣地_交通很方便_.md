地铁直达！广州“破万赞”的绿道徒步路线，免费徒步骑行遛娃玩水圣地，交通很方便！
=======================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

之前介绍过黄埔串联公园的云道徒步路线，大家好像更喜欢这种休闲散心的徒步路线，既能亲近大自然，又能呼吸新鲜空气～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbiawBBH5vFsXNmfC0VeaaAfHeQqgM4De8qGo7vLAaiaaiacMQGNXIsGmqQ/640?wx_fmt=jpeg)

  

今天阿珍再介绍一条黄埔休闲徒步路线，交通超级方便，一路上绿意盎然、河流悠悠，把夏日的绚丽全都装进心里面。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbzBQWeC8hIZ0s8VQOd3g7Yhq9bhbLY4rURP3p7mBVPBrzRZicgicbecFQ/640?wx_fmt=jpeg)

  

这条路线就是南岗河碧道，从长平地铁站出发，沿着南岗河徒步，经过好几个公园，最后到香雪地铁站结束。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbib8E81DkrWrWwca1nUp7iae0ibuNxq0FAiaLmKTGaj9ptMg7sRaLdicKn0Q/640?wx_fmt=jpeg)

  

全长大约7.2公里，用时2小时多点，全程都是平坦河边绿道，完全没有难度，老人小孩都轻松胜任。

  

除了徒步，南岗河绿道还很适合骑行，这边也有租车点，沿着河流骑一圈也是美滋滋。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRb1YSPk0gJiaxib23t3S8loIRGRmVyNzdWYE5SYkl5A2OAoeNFE1qPVcvA/640?wx_fmt=jpeg)

  

我们乘坐地铁21号线到达长平站A出口，出站往右走就是绿道入口。

  

自驾导航长平地铁站A出口，旁边的马路可以停车，或者导航南岗河悦动公园，旁边的马路也可以停车。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRb8Ztsw2tswg5wDlZxAhe2RNaVNXictHjz3C3kdlIOhDNf5xsoiaaJRGnA/640?wx_fmt=jpeg)

  

从长平地铁站A口出来往右走，就可以看河流和绿道入口，列车在横跨河流的高架桥上缓缓加速，旁边的现代化高楼蓝色玻璃窗特别引人注目。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbtDCIZfaQ63eNmf1XDhWcGaz6Uo1ibYPJtiaz8adKTjYP7iaZa5xeqpr2A/640?wx_fmt=jpeg)

  

而藏在闹市中的南岗河，绿植霸占了两岸，只剩中间河流静静流淌，有种自然原野与现代都市的碰撞美。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbKzTEgn2dvic9fA3H1HpLAwdtribyXxWLpylkcdsTdzLEDgIU1sH9OQ7Q/640?wx_fmt=jpeg)

  

南岗河绿道穿梭在各种高架桥和公路底下，不但可以看到地铁，还有有轨列车近距离从头顶掠过。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbiasvPdDN1Spia9W4L5jprgelCsnzCbRujMf77TC9jZUhyVbSm7akpmIg/640?wx_fmt=jpeg)

  

往前走就是周末遛娃圣地——南岗河悦动公园，这个桥底公园可以太好玩了，有超多的儿童娱乐设施。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbncoj9d3aHqb1kbHxk2TGjDIib3VQnYXhnib56Mn76wXOLKCQB3ic1doRg/640?wx_fmt=jpeg)

  

最热门的就是挖沙池和滑滑梯，还有荡秋千，面积足够大，后面还有羽毛球场和篮球场，也有公共洗手间。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbpAJjoYgncibmX49xzUK4kPbMJrkJv1ia5C3SdiahicuBPj0lnO9tvy9Gzg/640?wx_fmt=jpeg)

  

悦动公园完全免费，入口旁边有个游客驿站，这里可以租单车骑行，骑越久越便宜。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbicibfYffDNtEnZGnRb4b3qibIicH6G8RcRLrRETyx4HibSQmbkIdluCnUqQ/640?wx_fmt=jpeg)

  

带娃来徒步骑行，如果ta不想走，可以过来悦动公园玩一整天～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbqehgh7x2XEsjxMPn0IXbsIN9xHDpFia6G2fjPrUjXm71VFrsjFrp2rw/640?wx_fmt=jpeg)

  

再往前的大桥底下特别适合露营，大桥遮风挡雨，又靠近洗手间，可以搭个帐篷，明火烧烤也可以。

  

这里最不缺的就是草地和绿树，绿叶随风摇曳，空气中弥漫着青草香，很舒服的体验。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbI3NE9Lxicdv0RjH2zbS9nrxcicPEuh7FxBBaaEXODfa0ry3l9WsgiaK3w/640?wx_fmt=jpeg)

  

路上还会穿过桥底，骑行的话可以从上面公路经过。

  

南岗河的水质随天气而变化，下雨就比较浑浊，晴天就清澈透亮。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbvJbTWKTp4qTw6H0azGqI0vBrBT7MHg5kInvYibH8oRlMLiad02oQY1XA/640?wx_fmt=jpeg)

  

不少游客过来这边钓鱼，前面的小胖骑行钓鱼两不误啊，骑到一半就停下来钓鱼，这样能钓到鱼吗，哈哈。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbSkhS15FWbnIefAHaRyhcSCO7AdHBwANKh4CRRcKhRY3tmrdyCFcmfQ/640?wx_fmt=jpeg)

  

绿道的高架桥下有个浅滩和石板小径，大晴天波光粼粼特别好看，夏天可以过来玩水。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbqtb4YLOVxO0MmqBK5BBHK6pDk5xhNKtPyu8PP40eJPrzxgKFLtHZmA/640?wx_fmt=jpeg)

  

再往前靠近农业公园还有一个玩水点，就是没有遮挡，夏天比较晒，附近的大草地也是一个热门露营地，因为洗手间就在旁边。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRb1RgHov8LJHC6a3f9Zk94OKAC678SYumc3XD0svzB6gyAdGxzPTeq1A/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbhCKkicrEOSgy8bkV5Quof0keDzYnpVIC98myic7HMGXibD1f6qalLPI6g/640?wx_fmt=jpeg)

  

接着走还发现一片小小的花海，花朵很小个，火红色的花瓣衬托着橘黄色的花蕊很漂亮，不知道是什么花呀。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbzBt0EXJHMhciasj2TM8SKaHq7d3PQXKIyjMPKaCNssTPeLjHP68RLag/640?wx_fmt=jpeg)

  

路上还遇到一位大爷在桥底吹萨克斯管，悠扬动听的旋律，让桥柱上的海洋涂鸦增添几分灵动～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRb3WLe16rY7LR3UJUARxQVLqsWfcJDMDOdlXNibKXItKuiaAZHv6Qm7cVg/640?wx_fmt=jpeg)

  

我很喜欢玉岩中学前面这条林荫绿道，两旁高大茂密的树林形成一条绿色隧道，枝叶在阳光下闪动着生机，在这里漫步岁月静好。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOnIxuibOxE0n66mCoJ2N6zRbSkEokoUtyXzKoicAcuKUjdeqB8yS9c294aQz6ShY7ck1bicMqibUtjwWQ/640?wx_fmt=jpeg)

  

再往前就是南岗河文教湿地公园，绕个圈去香雪地铁站，附近是奥园广场和锐丰广场，顺便吃个饭再回去～

  

这条藏在城市中的河流绿道，走出了山野中的畅快感，越走越来劲哦！
