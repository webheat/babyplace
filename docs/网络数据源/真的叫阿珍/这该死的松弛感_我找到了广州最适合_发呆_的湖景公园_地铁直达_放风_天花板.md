这该死的松弛感！我找到了广州最适合“发呆”的湖景公园，地铁直达“放风”天花板
======================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

自从在广州当了打工牛马之后，我觉得最能快速充满能量的时刻就是周末逛公园。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGschLQQchusnic5Sbz90HksYp7ud5ethsPFibnSHsIWd3ZcOYlDDxP56w/640?wx_fmt=jpeg)

  

所以我会很喜欢广州这个特别有魅力的一线城市，不仅一年四季景色如春，而且还有逛不完的免费公园。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGQUkWucGXXkC0fB6xbfoJsibSdaEzDQ9A0atgtKZNyrl7F099TiaoibNuw/640?wx_fmt=jpeg)

  

人们常说的“公园20分钟效应”真的很神奇，周末去不同的公园悠悠散心，烦恼和压力很快就会随风飘散。

  

东山湖公园真的是一个特别适合i人发呆一整天的地方，这里非常有生活气息，有牵手散步的爷爷奶奶，有午休晒太阳的打工人，也有活蹦乱跳的小盆友。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGcibRlosZwmKicr8c6urhWtQxiaxFQRbtjKkeUYAka63FEOXOzWDsZJ5vQ/640?wx_fmt=jpeg)

  

一踏进东山湖公园，很容易就被周围的人或物感染，当你坐在公园长椅上，眼前是一片闪闪发光的湖泊，岸边的杨柳随风摇曳，水面的黑天鹅优雅嬉戏，你的内心会不由自主松弛下来。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGIX850d5qIvoPU8zBFdLf8dltfR6tEBoaK68cKw7xXyAhJuegKzVC1A/640?wx_fmt=jpeg)

  

午后的阳光透过树梢洒在身上，温暖来得恰到好处，微风轻轻拂过脸颊，闭上眼睛享受这纯粹的慵懒与宁静。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGFmgicMN0icBuzNooMvaXAXPOt0yQAT0JGfVbkQPibyPeKJPmYdUBWeWag/640?wx_fmt=jpeg)

  

身体似乎在长椅上生根发芽，久久不愿起来，我可以就这样呆呆坐一个下午，什么都不用想，也不用做。

  

这也许就是属于东山湖公园的松弛感，免门票免预约，想要放松一下心情，周末可以过来体验一番。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGQFpvcYovQ1viaRXMM6ICliamhCp7qB8JHAXkibzWwoDxHReKaPUmUicjag/640?wx_fmt=jpeg)

  

我们乘坐地铁6号线到达东湖站B1出口，出站往后走几分钟就到达东山湖公园西北门。

  

自驾导航东山湖公园正门地上停车场，2.5元一小时。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGiaOxWlmMajMQTvSr4mf4FUoXSEN28MXfYs4txBdkpSJdccdkKY0T3pA/640?wx_fmt=jpeg)

  

用湖光十色来形容东山湖公园最合适不过了，这里的湖泊是真的广阔，有环湖绿道和九曲桥，景色非常好看。

  

在岸边还可以拍到碧湖和广州塔同框，在蓝天白云的衬托下，美得像一幅油画。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGlWLNJGa71OWh6XRAZCssDsLU9dY591HVJcQx8ld1QOJdYETbNd2H1w/640?wx_fmt=jpeg)

  

公园还时不时能遇到可爱的猫咪，各种颜色都有，它们一点都不怕人，慵懒地躺在地上晒太阳，看起来都被照顾得很好，给它们拍照喵喵叫，好像在跟你打招呼。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGwtynP3C9JsvELwgHBGBrAF06l6WORp2xuB56nqmTv5mowNayv6GRSQ/640?wx_fmt=jpeg)

  

在东山湖划船也是十分惬意，周末划船的游客可不少。有脚踏船和电动船两种，租金在60～200元不等。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFG13SovPsVVwWyeSGwPyyFm97ZXjFXw9ExwjXV9jWk4WNgZeWnxRug2w/640?wx_fmt=jpeg)

  

和朋友一起乘着小船在波光粼粼的湖面摇摇晃晃，吹吹风聊聊天，放眼望去都是蓝蓝的，很漂亮很舒服。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOk6G6EBHGWica7qu5pxfCKFGa08qm4ta40uFShlJSH6Tc8kHMZ7DictiaKbkKM9zMadibdL7DJR4jV67w/640?wx_fmt=jpeg)

  

玩累了还可以去逛美术馆，陶冶一下艺术情操，还可以在咖啡厅坐下，喝喝咖啡，听听音乐，感受一下岁月静好。

  

人果然还是要去没有天花板的地方，心里的愉悦告诉我这一切都是真的。
