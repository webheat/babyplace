广州又发现一个适合“玩水”的地方，好爱这个“阳光沙滩”小乡村，免费露营玩水骑行秘境！
==========================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

广州这几天热浪来袭，我们必须用浪花拍回去，沙滩玩水才是夏天的主旋律。

  

其实不用出广州，在增城就有一片阳光沙滩，即便周末人也不多。  

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yMFWbR5FIku9icIQ2yeLYjZhhDmADN3IWJAVKWUuA8YbtXEXsMEnUh7g/640?wx_fmt=jpeg)

  

沙滩面积够大，沙子质地柔软，赤足行走很舒服，清澈的江水透心凉。

  

它就是增城蒙花布沙滩，免费免预约，露营、钓鱼、玩水、徒步、骑行、遛狗都很OK，简直就是夏日出游圣地！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yeY2Nx2P3c3XV9iacTicDzNfFCpcteFeDJvdpGaNvjyUoM2cXbBocMoZA/640?wx_fmt=jpeg)

  

就在正果老街附近，交通很方便，别光顾着吃云吞了，过来沙滩玩水才是正经事～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yeaiaN9LgStK1PNqbqTSjiaF5GRE3XqWj9r0nzSbUUlaW4JvTyH4aKJEQ/640?wx_fmt=jpeg)

  

我们乘坐地铁21号线到达增城广场站E出口，换乘增城17路公交到达正果车站，再换乘增城68路公交到达蒙花布村站。

  

自驾导航增城蒙花布阳光沙滩，停车场车站很多，3元一小时。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yibkmFAKLOnQFcvC5Ye9unbedDLtqKWaW64Jjr8iczx46gZgouVnYKHbw/640?wx_fmt=jpeg)

  

美丽的增江在蒙花布村绕了一个大弯，形成了这片三面环水的阳光沙滩，竹海与古榄林滤去暑气，风过处尽是荔枝的清香。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yHsUN2xbZNOyXyNXicj9LJqHOXYPsFnK19cwALxJdewbq7Hg6U02essA/640?wx_fmt=jpeg)

  

刚到村口，反而是这座拦河坝听江亭更加吸引眼球，红墙黑瓦典雅庄重，经典的中国式翘角屋顶古色古香。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11ymZSVko3BibCUNxANjMFWLsYqk5RrCNwcibbKSlMryIexFD9Y1k5mvDZQ/640?wx_fmt=jpeg)

  

听江亭中间还有一只大金牛坐镇，刻画得栩栩如生，寓意五谷丰登，水源充沛。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11ysG7sXvd4l1iaadnhAHkaWPF5pGVpwIjCSicicWERpJejjwWYLUtvu3MmQ/640?wx_fmt=jpeg)

  

站在听江亭上，左边是广阔的银白沙滩，右边是宁静的碧绿增江。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yj4TrPicYqOZsnkj9OvsfdgVVWoERDvVG6e2LDfJ0WficUg8MTKQRZkvQ/640?wx_fmt=jpeg)

  

但是最好别往下看，经过拦河坝的江水疾速奔腾，汹涌的水流声不绝于耳，多少有点心惊胆战。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yUibDr7AHNnUwqk6zicHbQJYcgtGUP8JFnxY1c9gINKKZgrkyVicVibY4Jw/640?wx_fmt=jpeg)

  

停车场就在沙滩上面，公共洗手间也在这边，河的两岸都可以下去沙滩，只能通过拦河坝过对岸。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yZVQNOxKVCloFXc0LJ2tuA6TTUqey7ZRBWwicFAtI0HfzhMBZ56L33mQ/640?wx_fmt=jpeg)

  

靠近拦河坝上游的水质最清澈，这边也是浅水区，适合小盆友玩水，但是家长一定要看护好小盆友。

  

现在这个天气，最好下午3点后再过来，带个天幕或者帐篷，不然会很晒。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yBlsI4r5iazkzP0Jooibkyvh5Fh5u0icOCGASpFqgdHB2XMmD6oiaE5sFtQ/640?wx_fmt=jpeg)

  

也可以和村民租天幕，好像是60元一个，周末沙滩上有村民摆摊，卖饮料小吃和玩水玩具。

  

一踏进清凉的江水，瞬间感觉自己活过来了。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yc4IibIBFibRs7zo5qYR8AGnRric56p2NrDR0DtrAIt4icy6dCLoCTfke3g/640?wx_fmt=jpeg)

  

周围的大人和小盆友都玩的不亦乐乎，挖沙建城堡，水桶捞小鱼，还有专门捡鹅卵石的，这里的快乐很纯粹～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11ypyz1JvV59wo8qnc8jVEVA4Qc3AibngD4WbtMJy5Fec01fibaRQqOQBRg/640?wx_fmt=jpeg)

  

沿着沙滩上方的栈道散步也不错，后面还有一片被青山绿水环绕的沙滩，拍照更好看，但这里是深水区，不要来这玩水。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11y1310qT3anz81qWl9DoLIztTLodNCicQSemzMTJVtjQVdXBqxGEY5nfA/640?wx_fmt=jpeg)

  

沙滩旁边还有房车营地和音乐广场，可以把这里当成一个小公园来散步。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yp3ibvcLvQqonNHBnyiaiaUaz6epTZLW4wpICibQ2PsLEhU51CQ4NnNCiaAA/640?wx_fmt=jpeg)

  

有色彩斑斓的大鲤鱼池，有背靠沙滩的秋千椅，有脖子不长的长颈鹿雕塑。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yzbshA2GFxVsYKvOZxnSvRO1mq1MPTm66mqSSBBFicVhVqzq8v3DjnHw/640?wx_fmt=jpeg)

  

还有“修成正果”的古榄园，姿态万千遮天蔽日，斑驳的光影随风晃动，在炎炎夏日也能感受到一阵阵清凉。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yWARlVeIsTC6UC7vgtkYlbaAjXTO8gKnlMjY0Eb6K9tymHm9OCCX0cg/640?wx_fmt=jpeg)

  

蒙花布村保留着原生态，经常在马路上遇到牛群，摇着尾巴在路边吃草，它们看起来很温顺，就是有时地上会有“地雷”！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOl9iaj31InFx6xScMJe5F11yw7KlQKvMCJNDtlXqQsjxxN6P087SicShLzl5DzLicMtADIcTxKkUenMw/640?wx_fmt=jpeg)

  

村里有农庄和民宿，如果是两天一夜的行程，可以去附近的正果老街、太子森林公园、白江湖森林公园等游玩，度过一个充实愉快的周末～
