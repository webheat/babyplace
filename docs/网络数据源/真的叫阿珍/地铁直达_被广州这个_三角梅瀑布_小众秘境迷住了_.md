地铁直达，被广州这个“三角梅瀑布”小众秘境迷住了！
=========================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

周末逛公园才是正经事，广州天河的树木公园开满了好多好多三角梅，整个河涌两旁都是，像瀑布一样垂下来～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37nbtBZFeWyjQQde2XVkEfR2pnFZ2XCZsCXVMl7KQ6AWyic5Dmar7h4IA/640?wx_fmt=jpeg)

  

火红“点燃”了整个河涌，蜿蜒绵亘望不到头，这种快要溢出的红，简单直接很有冲击力！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37X0ubRUSBaACwH1aiaFC4fNEibhjmJ52zHh1gohCgo6uOhk5HK3cjOT1A/640?wx_fmt=jpeg)

  

这条三角梅河涌有好几公里长，沿着河涌慢慢走，一来一回可以走1、2小时，真的很浪漫。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m375gBb62DOfSddUiaJjP94Gna5A5pSuZRb8JicK97xLqNOI47cG1Ix9QEg/640?wx_fmt=jpeg)

  

关键是这里的游客不多，身处闹市却把喧嚣通通阻挡，安安静静地踏春很不错～

  

树木公园交通很方便，乘坐地铁6号线到达龙洞站D出口，然后步行5分钟就到了。

  

自驾导航广州树木公园，进门就是停车场，2元一小时。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37eCA63Q1PkyB2Gy50zKK73f1g9tJJcj5S9FYC5tiaJQiaR5DFSc7orSKw/640?wx_fmt=jpeg)

  

公园就在广东省林业科学研究院内，刚开始还以为走错路，直到看到广东树木园的招牌才放心。

  

进入园区大门，过桥后就看到三角梅河涌了，想要欣赏广州的春和景明，不用去挤华农了，这条超长的火红风景线绝对值得过来！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37GqjD4JxYbniaoKbsQ8XyTqyu3ibaRwrhL3kialIWTUUeloQA8J3uHs92Q/640?wx_fmt=jpeg)

  

而且树木公园还是免费的，开放时间08:00-17:00，除了徒步赏花，这里也适合露营、遛娃、捞鱼、遛狗。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37ia07Jt5F75eaOKVCAd0PcljYltugqlNHDdcwNZdPUwMXoQOz82IUBZA/640?wx_fmt=jpeg)

  

沿着河涌走会遇到一片溪流大草地，有大树遮挡阳光，特别适合露营，小溪流浅浅的，水里的鱼可不少，可以带小盆友过来捞鱼～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37xUpLRdIKwJWsE6lFaEKrNNYRcibhiaiaD2uxf5glZDzArSzj2eAMevELA/640?wx_fmt=jpeg)

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37NQrj8j83IMAyckIoATTEa8VIbwQQa6ATjmIC5kuN1h382wx2Ff7GMg/640?wx_fmt=jpeg)

  

逛完三角梅河涌不要急着走，园区左边的树木园也推荐走一走，这里被遮天蔽日的大树包围起来，像走进森林一样，空气十分清新。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37R2HT5WIVFQIJKRSgJZK2gicujJttJFBl9Hla5WiciciakNcwJevibLVdiaPQ/640?wx_fmt=jpeg)

  

园区的树木有1000多种，但大多数我都不认识，只知道在这边散步很舒服惬意。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37X8tw7BXMpL88ibjW3pYNbEcOV8icybY9ZOFVDzOWYeTSDJjiahIKibYRPQ/640?wx_fmt=jpeg)

  

漫步在栈道上，一阵风吹来，四周响起了树叶的沙沙声，深深深呼吸，那种由内而外的松弛感，自然而然地散发出来。

  

此时此刻，风是凉爽的，光是温暖的，心情是自由自在的～

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOmlPGffFcc6nL34u9Ds0m37TLc0xIGdYzxTyh4vYVZwNeukun7AL5NBM8EodIkSeMDrT34ANiafSOw/640?wx_fmt=jpeg)

  

树木公园看似普通却带来很多惊喜，如果要找个宁静清幽的地方散心，我第一个就会想到这里。

  

趁着花期还在，不要错过这个宝藏树木公园了！
