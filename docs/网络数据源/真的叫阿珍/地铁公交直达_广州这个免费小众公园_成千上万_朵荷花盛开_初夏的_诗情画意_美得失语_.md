地铁公交直达，广州这个免费小众公园“成千上万”朵荷花盛开，初夏的“诗情画意”美得失语！
===========================================

原创 真的叫啊珍 [真的叫啊珍](javascript:void\(0\);)

在小说阅读器中沉浸阅读

大家好， 我是阿珍。

一个热爱旅行、热爱分享的女生，

跟着我，一起感受这个世界的美好！

  

“出淤泥而不染，濯清涟而不妖。”这两句诗从小听到大，但直到我站在淤泥边缘，近距离凝视那破水而出、不染纤尘的花朵时，才真切地感受到诗句背后的那份震撼人心的生命尊严。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3Sw3Lb2RWh8q2AOAUbnH76VWFdN5ibUrbThpsq9eQXQj2MIyfoKXYCDXCA/640?wx_fmt=jpeg)

  

我可太喜欢这个季节的广州了，各地的荷花陆续绽放，正是赏荷的好时机，每天都心心念念这份纯洁的景色。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3Sw5fRHjMWGiaBFVgrwJHYKTf4xRvUrA9dSV9xm1g9AxgOYIyrticbS1Anw/640?wx_fmt=jpeg)

最近阿珍又发现一个小众赏荷地——南沙东涌公园，这里的荷花不仅开得明艳动人，而且没有各种长枪短炮和人挤人影响心情，简直就是夏日赏荷圣地。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3Swld2AEpuN5VViaKlwpzSCardo4UlpSnZ2jZnOy1ibuOwKkZulMC9oPu1w/640?wx_fmt=jpeg)

  

去东涌公园交通便利，乘坐地铁4号线到达东涌站B出口，前面就是公交站，换乘南35路公交到达东涌镇政府站下车，马路对面就是东涌公园。

  

自驾导航东涌文化广场停车场，再步行7分钟到达东涌公园。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwicmicMexFCDoccLHm4MicibYcuU9UiaxcbP6arHFyMrD4QszNBAmrUqAuAw/640?wx_fmt=jpeg)

  

东涌公园面积不算大，但荷花池就占了一半以上。当我走近湖畔，荷叶在碧波之上肆意铺展，紧紧相拥无边无际，绿意早已占据了我的视线。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwAYiaiaicAnWea1z8DPBF5zW69qJmsUPbibQdK7RHLDsW5ucAm0q7yzFnDQ/640?wx_fmt=jpeg)

  

在这片绿意之中，绽放的荷花犹如繁星点点，悄悄从层层叠叠的荷叶中探出娇嫩的脸庞，跟随微风轻轻颤悠，怯生生地注视这番天地。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwxiaoYdXWiaGraavdurLt9VAvEIuyzhU13BrFbWGnRLFwhrYDX2uMsFGg/640?wx_fmt=jpeg)

  

虽说6、7月才是荷花的盛花期，但我感觉东涌公园的荷花生物钟被拨快了，粉嫩凝黄优雅绽放。路过的游客无不停下脚步，想把这盛景占为已有。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwNHeGJTia1mAqC1TJPbGhpScpdMJt68eo2WVEngY2tUUSy8PsUJzZ73A/640?wx_fmt=jpeg)

  

当我拖动高倍数长焦镜头，晶莹剔透的露珠在荷叶上滚动着，叶面的脉络细密如画。荷花早已亭亭玉立，粉白相间的花瓣深处，是黄蕊点点的浪漫，恰似莞尔一笑的明眸。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwSFsvtxEmzu0h5siaLUZuV6hz18Y0DOloTY7iaVPV7QZQkYdaS5PQCRJQ/640?wx_fmt=jpeg)

  

那沁人心脾的荷香，裹在风里，一阵阵，一层层，浓淡相宜地渗入我的肺腑，仿佛整个夏日都凝成了这一股清幽。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwPx52A50p2liaxcg4Ricia4RCgP9uJ9nMvZhPzCFcVOqID3kicXThGXuKgg/640?wx_fmt=jpeg)

  

没想到这里的荷花可以美成这样，感觉比之前龙归南村的荷花还要美得多得多。

  

跟人之间的距离也很近，似乎伸手就可以触摸到娇艳的荷花，观赏体验特别好！

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwIx0PdFjjoibeYx26jdgLSqOqH3nI7DEhyzfm2Pic4urbnQiahbAhPjcqQ/640?wx_fmt=jpeg)

  

东涌公园也是一个充满生活气息的地方，大爷大妈在荷花旁喝茶聊天，大人带着小孩过来亲近大自然。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3Sw0FNbcHSqZiboJraDjIBqSp1m61RLrWXesgYgxZUnmolOHT838doB8ug/640?wx_fmt=jpeg)

  

公园还有一条假山叠石做成的小溪流，夏天小孩子可以过来玩水，水质很干净清澈，挺不错的。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwickkmCbhJ2zuTggVdZicgYibbe9EQTWofNibMn3QZbAufQMRPePiaVGCibibQ/640?wx_fmt=jpeg)

  

一位头发花白的大爷为了给小孙女捞鱼走下荷花池，小女孩捧着一桶小鱼笑得合不拢嘴。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3Sw5gG8bvfObUBiaDnZB2t3n536T1vfUGMgicicQgfq1YobcQnJ1uzHZ22iaw/640?wx_fmt=jpeg)

  

大爷擦了擦沾满淤泥的双腿，笑着摇了摇头，眼里满是爱意，或许这夏日荷景和玲珑小鱼，会成为小女孩难忘的童年记忆。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3Sw4j9kKxJGrezicnCJOObQpNciciaic5e3fN2y99QXBqQpBmZYaDtpoxibzVw/640?wx_fmt=jpeg)

  

欣赏完美轮美奂的荷花，东涌的瓜果绿色长廊也可以去走一走，定位东涌绿道湿地公园即可。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwWICeiaPvCKhjmp0XlRmeW02p1ibticuMQAl69j7bjVnrm2uibicleqJGecg/640?wx_fmt=jpeg)

  

就在大桥底下，可以免费停车，桥底还有一个小型儿童公园，有滑滑梯、传音筒、障碍攀爬等设施。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwKsbgenmPBDnUHnFkMnh8CKI6Gia2TMSFv7eibOdYibhIqkC041NRyFKFg/640?wx_fmt=jpeg)

  

穿过儿童公园一直走就是瓜果长廊，入口处有村民在卖蔬菜水果，价格不贵。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwFcqhIyjptAJLOn5VNUcnf5UZ0TwcZrzIibU3uoR7Gg1bk4ic9avM2ZqA/640?wx_fmt=jpeg)

  

长达1.5公里的瓜果大棚，左边也是一个超美的荷花池，右边则是果树和鱼塘。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwnHHAsSvicFgH5QQkvN70ANKbAujK3yjDPLLbOR0xJxjCn6vy1lZonFQ/640?wx_fmt=jpeg)

  

这条长廊目前没有瓜果，但后面开满了各种颜色的鲜花，我最喜欢的是这一段蓝紫色牵牛花，开得满满当当，十分浪漫。

  

![](https://mmbiz.qpic.cn/sz_mmbiz_jpg/qibia2QdpuAOlcuT3lGib9TWyRT4Y6JL3SwSX5HjXoEJGXgWGXURdEyFKooTlOicvjMpbSDaFeAOneWmJ5858q2CmQ/640?wx_fmt=jpeg)

  

人还是得多出去走走，不一定是远方，也可以在熟悉的城市里，寻找初夏的诗情画意。
